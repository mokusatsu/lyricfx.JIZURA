# READONLY64 — billboard transport qualifier before grounded reflow

Status: read-only proposal. Native62 is parent-accepted; canonical63 JA/EN and six AFTER checks are still pending. No implementation, app, transport or placement certificate is supplied here. Existing eight native fixtures establish source/catalog/paint parity, not generic radial-gradient capability or a safe adapter. External03 is a proposal, not authority for a new geometry policy.

## Selected smallest next step

Prepare a billboard-only, zero-offset, synchronous original-live-root/effective-FX record→replay qualifier. This is the missing fidelity foundation before source-specific reflow: current09a admits original-root transport for selected D layouts including bulbs, but not billboard; radial-gradient recording is restricted to C. Generic replay's clip and gradient branches can import getTransform through setTransform, whose low bits may differ from the live native root. Merely adding billboard to a membership list or permitting all D radial gradients is insufficient.

The pilot should use one existing wide four-glyph L3/tag fixture and one existing portrait L4/tag fixture, stock cut/cut/none and still only, pinned fonts, actual default-context backend, no area/mask/custom callbacks/media/effects/events/extra foreground. State the exact supported effective FX, camera, scale and source/helper/font identities. Include actual nonunit motionScale/effectFx comparison only when the original branch is independently qualified; otherwise refuse it explicitly rather than inheriting bulbs51. Begin at zero offset; no claim that this translates a grounded billboard correctly. Ordinary unflagged legacy paint remains untouched.

A narrow source-owned material event can preserve the original main-only rectangular face clip, each actual cone's radial creation arguments/matrix/three ordered stops/four-vertex path/fill state, and the following face-illumination fillRect, in the original operation order under the unchanged live root. Retain zero-alpha calls. The material scope ends at the original restore before lamp arms, housings, lenses, main text and tags. Require the source layout, owner, pass, catalog completeness, exact root coefficients and absence of unqualified local operations before admission. Replay should use the live root and original native operations; do not reconstruct it with setTransform(getTransform()). Keep generic gradient/clip replay byte-identical. The precise event representation is a later source-review decision, not an invented existing API.

All existing billboard owners remain PRIMARY: posts, braces, deck, eleven uprights, rail, ground line, frame/face, every source-conditional cone/illumination/lens, housings/arms, complete lyric and No./time. No owner is reclassified as auxiliary to make replay or placement easier. Owner catalogs enumerate possible owners; actual source calls retain each literal source condition and alpha. Source62 already records board.illumination as main-only conditional.

## Meaningful qualifier evidence

Use independent original native closure/page, modified-native OFF and ON, then zero replay on separately source-rebuilt roots. Compare full RGBA, primitive/item arguments, actual creation/paint/clip CTMs, gradient stops, path commands, effective FX, full source catalog, BB, RNG call sequence and all font/text state. Include weak .1 lamp flicker, strict lt>t1 and lt>t1+.25 neighbors, .01 cone and .5 lens thresholds, entry/held/exit/tail, all main/A/B, fractional roots and nonunit scale. Negative controls must reject unsupported source/helper/renderer/recipe drift before destination paint; avoid new Proxy/prototype/security tests. Source62's prepared128-root pure-data codec regression and its actual result do not establish Canvas transport correctness.

Synchronous same-turn scope only, unchanged participating source/helpers/fonts/context. No post-record cache, decode or stale-program rejection claim. A future visible adapter must independently revalidate current source/fonts/context and preflight before any visible write; zero transport does not supply atomic visible-frame admission.

Actual Renderer source clock must be derived afresh: tq from fps quantization; pass tp=max(0,tq-lag), lt=tp-cut.start, ltb=lt+lag, source step=floor(tp/(1/24)+1e-6), actual pass selection/fade/ghost limits, and realTime when set. Source62 direct probes use supplied own-clock tuples with actual24Hz step; they are not exhaustive wholeRenderer coverage. A finite native60fps matrix is a bounded diagnostic unless exact Number-preimage equivalence and current source bindings are proved. No continuous/libm/raster bound is inferred from sampled pixel parity.

## Grounded reconstruction is a separate placement step

Uniform stage translation of every owner moves the ground line and support feet, violating original grounded intent. After the qualifier, a smallest reconstruction diagnostic could expose a board writing-field origin/width/height while leaving groundY=.94H and ground-line endpoints fixed. Recompute both post lengths and their top positions from the new board bottom; recompute brace connections at the original .25/.9 fractions. Deck/eleven uprights/rail and lamps stay attached to the board. Their original dimensions, sweep, strict source lampOn, RNG seed/i/step, rise, pOut, painter order and all ghost behavior remain until a separately declared redesign. Lamp housings stay BELOW the face and beams point upward through the original face clip. No cast shadow, socket or extra ground fill is invented. Keep original No. and fixed cut-start time; no elapsed-clock substitution.

First compare original geometry at zero, then source-sized board repositioning with support reconstruction, retaining native text/font/wrapping if feasible. Only after measured failure consider writing-field aspect/reflow, then a declared local type-size family if no explicit user size is imposed. These are candidate strategies to compare, not a universal move/split/shrink priority or automatic winner. All source character order/index mapping, full tags, lamp count/order/cadence, lamp/body relationships and source movement must remain inspectable. A new board aspect also changes the native source-derived lamp geometry; that is a declared aesthetic redesign requiring an independent geometry oracle and native60fps comparison MP4, not stock transport parity.

Circle center/radius/margin belong to the candidate evaluator, separate from font/field templates. Start with default(.5,.42,.2), then explicit bounded variations of position/radius using the same measured native support. Ground/post/brace/catwalk/lamps/text remain strict primary obligations; no ground exception. The authorized source-moving entry/exit circle policy, if applied, must be explicit and never waive held or stage obligations. Preserve unclipped support for stage tests; pixels or returned main-only BB cannot prove stage fit. Conservative envelope conflict is not an actual-ink collision or global impossibility. Unsupported circle/domain/font/backend/geometry cases return a typed unqualified result, preserving all failures; no paint deletion, extra mask, clipping or tail shortening is a fallback.

The direct visible goal is a readable illuminated roadside sign that avoids the chosen circle while remaining anchored to its ground, rather than a floating miniaturized composition. This proposal adds no implementation and does not preempt canonical63 failures.
