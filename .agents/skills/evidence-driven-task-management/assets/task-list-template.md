# Task List

このファイルをタスク一覧の正本とする。会話、Issue、PRなどと状態が異なる場合は、このファイルと該当する `tasks/<TASK_ID>.md` へ正式な状態を反映する。目的、完了条件、検証証拠などの詳細は個別ファイルへ記録する。

## 運用ルール

- タスクID形式: `<PREFIX>-NNN`
- 発行済みIDを再利用しない。
- 取りやめたタスクも削除せず、`中止` または `対象外` と理由を記録する。
- 原則として `調査中` または `実装中` のタスクを同時に1件だけにする。
- 完了条件と必須検証を証拠付きで満たした場合だけ `完了` にする。
- 進捗率は補助情報とし、必須検証が残る場合は100%にしない。
- 一覧は1タスク1行の状態表とし、詳細記録は `tasks/<TASK_ID>.md` に分離する。
- 新規タスクでは、一覧の行追加と個別ファイルの作成を同じ変更で行う。

## 状態定義

| 状態 | 判定基準 |
|---|---|
| 未着手 | 調査も実装も開始していない |
| 調査中 | 仕様または既存コードを確認している |
| 実装中 | 対象の変更を行っている |
| ローカル検証済み | 必要なローカルテストや確認が成功した |
| 実環境検証待ち | 必要な実環境確認が残っている |
| 完了 | すべての完了条件と必須検証を証拠付きで満たした |
| 保留 | 外部回答、権限、仕様決定などを待っている |
| 中止 / 対象外 | 実行しない判断と理由が記録されている |
