`person-rvm-alpha.png` is a 128×128 alpha matte produced by the app's RVM model from a frame of a short synthetic pan of the publicly available TensorFlow example image [Grace Hopper](https://storage.googleapis.com/download.tensorflow.org/example_images/grace_hopper.jpg). It contains a model-generated person mask rather than an artificial geometric region. The test uses it as a matte fixture; it is not included in the application distribution.
