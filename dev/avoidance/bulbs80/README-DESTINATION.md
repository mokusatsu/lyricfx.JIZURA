# Unregistered actual-transform destination experiment

`destination-replay80.js` is a verbatim checkpoint of the reviewed80m source-only numerical helper. It is not loaded by build.py, HTML, renderer, safe-adapter registry, finalizer, cache or UI. It accepts an explicitly unowned input model, issues no certificate, and requires the experimental compiler/proof/quality/geometry dependencies supplied by its external harness. The test-only afterPristine observer is not an authenticated rendering boundary.

Unlike the earlier zero helper, it calls the original P.shift with the original inverse arithmetic and native Canvas operations. It checks the unshifted root bit-for-bit, then reads the actual shifted root and glyph matrices. It reuses input-derived local geometry/real metrics while rebuilding semantic groups and all-held glyph supports/quality. It never replaces actual destination matrices with an ideal delta added to old bounds. Static source face/ring/size/text inventory is reused; old aggregated glyph bounds, minScale/counts and quality flags are not copied into the new result.

The same-runtime80m experiment compiled once, matched all four zero replays against80l exactly, and evaluated input-derived finite candidates for an upper and right circle. The parent independently checked all1463raw records and both decoded/gzip hashes. For each circle it verified727own clocks, containment of28840actual destination supports and28840native supports,3977actual glyph matrices,3332held glyph supports, strict stage/circle conditions and2081exact Fraction quality predicates. The accepted test deltas were[0,94.40105101731228] and[-122.98061107748151,0]; these are derived regression results, not production constants or a supported-input lookup table.

This evidence is limited to the tested JA text/seed/native family and conditional Canvas support model. It does not establish model ownership, stale/cache admission, ordinary-frame rendering, UI publication, general-input destination qualification, or the other five effects. Candidate replay took roughly3.61/5.58seconds with repeated diagnostic accounting; this is not a practical circle-edit/frame/UI performance acceptance. The helper's8MiB limit concerns exact-Float64 serialized working state, not JavaScript heap/RSS.

The evidence stays outside Git at `/workspace/jizura-logic-evidence-20261027/bulbs-destination80-actual01` and `bulbs-destination80-parent-review01.json`. Generated HTML, raw files, fonts and media are excluded from this checkpoint. No product behavior changes by saving these files.
