# Bulbs80 experimental verification unit

This directory is a work checkpoint, not a product adapter. No build, HTML, private D registry, frame issuer or UI loads these files. No placement certificate is issued. The six fixed comparison approvals are unchanged.

`held-quality80.js` collects all qualifying own passes (`lt>=.35 && pOut===0 && q===1`) from a source-derived scalar compiler. It checks stable native/recipe text, sizes, subtitle, face/ring point sequences and N, and retains glyph source indices/lines. Half/full-width spaces remain logical slots but are excluded from modeled source paint identity, matching `J.drawItem`. Counts are modeled coverage, never observed paint counts.

It normalizes actual glyph supports outward through the actual positive uniform root, retaining the original1fontpx/2devicepx conditional foundation. Exact dyadic cross multiplication applies the global held minimum scale while preserving neighbor/row/caption/outline `>=` and disk clearance `>`. Text AA, outline's separate2+3.24 and disk's separate2+gap are retained. All potential halos and combined main/ghost glyph supports are stronger sufficient conditions; a rejection is conservative unproved quality, not an ink collision. Soft4.86 shortfalls remain nonfatal lower-bound diagnostics, not old per-clock witness counts.

Failures retain exact total/per-criterion counts and an explicit first16witness limit; omitted witness counts are reported and all predicates continue. A future compiler integration must count the collector, current cursor/glyph work, quality evaluation/results and witnesses under the existing serialized working budget. This is not a JS heap bound.

Run the independent pure arithmetic/condition tests with:

```sh
node dev/avoidance/bulbs80/held-quality-test.cjs
```

286checks currently pass: exact-dyadic inverse containment including negative/zero/nextafter inputs, comparison contact boundaries, nonfatal soft gaps, space/index identity, two-row and separate ghost inventory, structure/input rejection, no-held rejection and explicit witness accounting. These tests do not qualify Canvas rendering, support containment for new input, destination translation, a runtime certificate, cache invalidation or UI behavior.

The source-only compiler prototypes and literal evidence remain outside Git under `/workspace/jizura-logic-evidence-20261027`. The latest measured approximately2second preparation is a conditional intermediate result, not a user acceptance threshold or formal/UI performance pass. One second is only a reference goal. Remaining work includes source-connected collector budget verification, held quality against offline native evidence, circle destination actual CTMs/quality, private binding, cache admission/invalidation, ordinary frames, nonfixed/EN cases and AVOID-017 UI integration.

Planned runtime work counts remain explicit: one geometry/quality compile on a fresh supported input; zero fresh geometry/metrics compiles for a circle-only change (destination CTM/support/quality validation is separate); one new compile for a permitted font resource/revision, text or seed change; zero compile/quality scans during each ordinary frame. Unsupported font IDs, explicit sizes, FX/stage domains must reject rather than return a stale result. These are implementation contracts still awaiting the cache/binding gates.
