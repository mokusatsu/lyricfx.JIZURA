# Unregistered plan-binding experiment

`plan-binding80.js`, its test and the 09k test fixture are byte-identical to the reviewed80t source. The two zero-context patches reproduce its reviewed09a / 09k overlays from the product files at `68ce5b25`; use `git apply --unidiff-zero` only against that exact base. The parent applied both patches to isolated copies and compared their output byte-for-byte with the reviewed sources. Nothing in this directory is installed by the product build.

The factory models an opaque certificate bound privately to an exact finalized plan, resident ticket and source/trajectory values. It rejects decoded aliases and stale ownership; retained proof records use a fresh serialized-byte getter. The proposed finalizer overlays mark unsupported cuts belonging to callback-bearing D adapters, so their failed original-cut fallback can be detected before drawing. Manual / locked / no-active-region paths and callback-free legacy adapters remain unchanged. The actual private controller, bulbs adapter, real J.plan ownership and renderer hook are not connected here.

Run `node plan-binding80-test.cjs` in this directory. The parent independently ran79 mock protocol, source-fragment and budget checks. These do not establish real callback no-compile/no-paint behavior, actual finalizer / codec / frame admission or Canvas safety. Source and numeric tests for those dependencies must pass before applying the patches to the product.

Reviewed evidence is under `/workspace/jizura-logic-evidence-20261027/bulbs-plan-binding-source80t`; no media or raw data is included in Git.
