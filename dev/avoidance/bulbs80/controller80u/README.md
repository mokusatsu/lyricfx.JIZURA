# Unregistered owner/controller binding experiment

These source-only files join the previously reviewed 80r owner and frame controller to the private 80t plan-binding factory. They are not loaded by the product build and do not register the bulbs adapter. The two JavaScript sources match the 80u evidence copies; the test differs only in paths to the existing repository fixtures.

Run `node dev/avoidance/bulbs80/controller80u/integration-test.cjs` from the repository root. The parent independently ran all 26 checks. The test loads the actual owner, controller, private binding and registry sources, but uses a mock compiler, mock drawing context, mock final validator and a synthetic bitmap counter. It exercises one preparation, mutable plan issuance followed by trajectory and finalization, freezing and admission, a second stock renderer, and rejects aliases, changed text or circle, an insufficient result, an unsupported marker, missing noPost, replaced dependencies and an evicted model. Frame admission does not call the mock compiler. The counter is not evidence about real Canvas writes.

Real `J.plan` / finalizer ownership, cleanup after a failed finalization, actual Canvas and renderer behavior, adapter registration, ordinary UI options, asynchronous preparation and performance remain unqualified. `noPost` and `fast` are required by this prototype; ordinary UI calls do not consistently provide them. The prior product registration and behavior are unchanged. See the 80u source and test evidence under `/workspace/jizura-logic-evidence-20261027/bulbs-binding-controller-source80u`.
