# Composed-plan clock and empty-layer scope (86bu)

Source-only proposal; no ordinary UI, performance, Canvas, placement-safety, or new human acceptance. Shared tiles helper and product build/registration are unchanged.

`generate.py <repo>` derives the scalar generator, model owner, and post guard from 86be/86bj/86bp. It replaces fixture-only 4-second clock operations with `compose-scope86.js`, retaining complete Float64 preimages and B/A/main selection. No plan field is rewritten. The owner snapshots the new helper and functions and verifies original clock, selector, media, and camera identities. Existing stage960×540, viewport720×405/.75, motion/chroma/ghost, family, event, placement, context, font, generation, cache, budget and failure guards remain.

Empty composed media/foreground are accepted only with exact plain-data shape, no cuts, duration identical to the plan, `applyLyricBackground:true`, normal blend and opacity100. Objects remain in the original plan. `false` is unsupported because Renderer.frame tests `plan.media?.applyLyricBackground !== false` (src/09_render.js). Missing style glow is admitted only alongside texture0: source post uses `(glow||0)>0` for scratch and a texture-multiplied effective glow. Other glow values remain unsupported. Stock push camera ignores camP (src/05b_registry.js); camP remains part of full owner input identity. Actual Canvas equivalence for these newly admitted values is pending.

Clock scope is one cut at +0, fps60/koma0, finite end>.6, exact dur=end and displayEnd=end, finite in/out within duration, finite plan.duration>end and <=511/60. The quantized tail must have no active selectors on any pass. Clipped/short-tail/multicut/unproved domain are typed unsupported, never padded. 512-state and 1536-own limits remain. End/start/realTime are not interchanged; the original division/addition/floor order and firstTime/preimage semantics are retained.
