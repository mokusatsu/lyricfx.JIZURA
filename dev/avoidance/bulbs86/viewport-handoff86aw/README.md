It requires the genuine opaque ready token, completed private quality/evaluation, candidate index and exact current source plan. The selected delta comes from the owner's private finite evaluation. The callback can synchronously borrow the existing model, private viewport context/profile and selected candidate. This grants no safe certificate or frame admission.

Error, stale data, asynchronous/thenable result or budget excess revoke the ready job. The temporary accounting callback rejects calls after the borrow ends. The unchanged token remains valid after successful normal borrowing and is disposed by ordinary owner cancellation/eviction. No ctx/model is returned through a public progress/summary API.
