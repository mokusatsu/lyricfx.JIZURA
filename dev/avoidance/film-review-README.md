# Focused native MP4 review (AVOID-006)

`film-review.cjs capture local-20261021-01` creates a fresh, immutable bundle. Do not run final capture until source is frozen and parent code review is complete. `--smoke` writes 40-frame diagnostic output (includes the1.5s fixed PNG) beneath `work/film-review-smoke`, not acceptance evidence. System H264-capable Chromium is selected with `JIZURA_BROWSER=/usr/bin/chromium`.

New film pairs capture the actual native renderer at n/24 for 96 frames (4 seconds). Their fixed fixture has a four-second cut; source motion-clock quantization and per-pass placement summaries are retained for every frame. Complete raw observations are retained at frame3 (0.125s),7 (0.291667s),15 (0.625s),36 (1.5s),90 (3.75s), plus the initial complete plan and its interval certificates. Full polygon observations outside these five keyframes are evaluated transiently and hashed but are not retained. All certified frames assert strict circle clearance and envelope coverage; excluded cases remain explicitly labeled diagnostic output. No browser wall-clock playback or video screen recording is used for these new videos. PNG frames stream directly to libx264; yuv420p, 24fps, faststart, duration and decoded frame count are independently checked by ffprobe. A native PNG and the exact guide-composited encoder input PNG at frame36 (1.5 seconds) are retained for each side. Their hashes must equal the corresponding raw capture record. The validator also reruns each side at1.5s using the pinned fixture, engine and fonts and requires exact native PNG SHA256 equality in local and public mode. Only explicitly linked PNGs are available on the review page; videos use native controls and preload=none.

Baseline source is pinned to3e2ff804fac2e94dce79039ddf7a46ec19221494 and must exactly match immutable old04 source before its shared engine can be reused. Candidate source is retained losslessly compressed plus the executed normalized HTML; all src file identities and unchanged fixture identity are recorded. Candidate and tool changes during capture are rejected. Original fonts, font-symbol definition, and three legacy WebMs are referenced through old04 hashes. Other motion MP4s are honest transcodes: old manifest actual renderer frame counts differ from the25fps WebM container and cannot be increased by encoding. They are labeled historical examples and never presented as fresh animation evidence.

`film-review.cjs validate <bundle-directory> [<exact-public-bundle-URL/>]` verifies all bounded assets, source identities, complete keyframe raw observations and all96 per-pass summaries, actual MP4 codec/frame count/faststart, JA+EN initial transfer, and native playback/decoded-frame/pause/seek behavior in Chromium. Public mode additionally fetches every manifest asset and manifest through the configured browser proxy and verifies raw SHA256. No TLS bypass is provided. Initial page loads must fetch no MP4, WebM, PNG, font, engine, or observation data; no scripts, canvas or iframes are allowed. The initial page consists only of HTML, native video controls and links. Browser timing records and getVideoPlaybackQuality are included in its JSON stdout.

`film-review-test.cjs` checks actual valid media and rejects malformed/truncated media, wrong fps/frame count and late-moov MP4. `film-review-asset-test.cjs` verifies byte hash rejection, unsafe paths and symlink rejection without media processes.

No tool opens images or videos for visual judgment. Isolated visual review, full final Jekyll output audit, public hash checks and human review remain separate required evidence. Do not overwrite old bundles or treat scratch smoke output as final review evidence.

The11 complete core/focused test logs are stored as lossless gzip with encoded/raw byte lengths and SHA256. Validation restores them only into a fresh tool-owned temporary directory, runs the unchanged existing `checkFunctionalReceipt`, and removes that temporary directory on exit. Test summary success never replaces the raw logs.

`film-review-font-test.cjs` verifies current fixture coverage, rejection of an uncovered glyph, and failure before bundle creation/browser launch. Capture preflights all three fixture texts against the immutable font and symbol cmap; validation repeats this check. No substitute font is accepted.

Validation registers both the decoded-frame callback and seeked listener before changing currentTime, avoiding a fast-seek presentation race. `film-review-seek-test.cjs` checks synchronous decoded/seeked ordering and error cleanup. Every active video is scrolled into view; viewport/document visibility and full-playback quality before/after deltas are recorded without relaxing drop/stall limits. Results checkpoint before assertions into a fresh incremental receipt, with the failing video path preserved.
