Model keeps a single static input snapshot, immutable per-own clock/root/support/glyph projections and numeric lookup index. Finish transfers the one row/index arrays into the immutable output, nulls the builder references, and counts the full output once; it does not create an uncounted second model array. Caller reservation and clock/source/circle data remain included. Fail/cancel drops partial row/index/static references and closes the collector; no partial model can be returned. The model's fixed-width encoded resident byte length includes its final metadata.
