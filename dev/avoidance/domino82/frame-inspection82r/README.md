Commit publishes an immutable plain deep clone of the prepared J.plan-derived input plus ticket; native data remains identical but this is an unfinalized experimental plan, not official finalizer/cache/UI ownership. Rendering must use that published plan identity. Copying/freezing a plan cannot mint a ticket. The clone prevents mutable caller plan growth from invalidating cached ticket byte counts. Product integration must seal source binding/admission/failed-plan before-bitmap behavior separately.

Finish/abort release the one active record, so old external tokens retain no model/plan/pass state. If actual paint throws, data token is aborted but bitmap/Canvas rollback is not asserted.
