# Observed affine box support82c — pure arithmetic only

Computes outward intervals for a local box plus nonnegative local pad under a supplied finite6component affine matrix, then a nonnegative device pad (default2, the existing conditional model's raster guard). Every multiply/add/subtract rounds outward to an adjacent Float64; negative/zero coefficients use the appropriate interval endpoint. Overflow/invalid box/matrix/pad is typed rejection. No new universal Canvas/raster error bound is claimed. Matrix must come from the actual native operation sequence, not JavaScript composition substituted for Canvas CTM. Glyph ink needs actual current font/TextMetrics plus the existing local font-space pad; strokes need actual lineWidth readback/join/cap/miter/dash. Those acquisitions are not implemented here.

This new primitive is needed because the prior billboard/bulbs interval helper only accepts positive uniform axis matrices, while domino face/pip/glyph have a rotated actual root*M. Native JS-transformed polygons remain under root. Boxes may conservatively include nonpainted corners; no safe candidate or global impossibility follows. Normal/source-X clipping and wholeclock/primitive provenance must be checked separately. No fixedoffset, newclip, support model/compiler, owner or UI registration.

`node affine-test.cjs` independently reconstructs Float64 inputs as BigInt dyadics and checks every padded corner lies inside result, including positive/negative rotations, nonuniform/sheared/reflected/singular/zero matrices, negative coordinates, subnormals, tiny/large scales and overflow rejection. This verifies arithmetic enclosure only, not actual Canvas supports, text metrics, AA premise or runtime qualification.
