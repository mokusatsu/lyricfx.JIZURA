# Domino private prepared owner82p — source-only

Unregistered experimental owner. No adapter/frame/UI installation, renderer authority or imported-model adoption API. Begin privately dense-clones the exact current plan (including circle and±0), checks one native domino cut/whole-tail upper circle/fixed source operations, and evicts the previous resident before allocation. It internally creates a fresh dedicated960×540 Canvas and stock Renderer. Only progress and opaque identity tokens/handles escape; context is never passed to a callback. Native Canvas construction/getters and recorded prototype descriptors, source/helper functions and font dependencies are checked. Initial letter/word spacing must be set by native setters and read back0px. Exact phase snapshots reject drift; empty spacing is never equated with0px.

Two phases: unchanged82i full native candidate compile,82m interior midpoint, then all active own native/shift sampler pairs into82o's immutable destination collector. Every own restores private context before yielding. This is finite whole-clock numeric preparation, not draw/spy replay. It may still be expensive and has not passed real Canvas or UI practicality. No synchronous generation is connected to frame/finalizer/UI. A future controller must independently bind actual render context, noPost/fast/scale1 options and Float64 preimage realTime; t=n/60 evidence alone is not an arbitrary-time admission rule.

Ready models remain private. Commit moves (not duplicates) ready model, clock, input snapshot and dependencies into one resident record, releases the private surface, and returns an empty opaque handle. Validate checks exact input and current generation/source/font dependencies without recompiling. New text/seed/circle or legitimate font/revision/face replacement rejects old handle; explicit begin captures current state anew. Cancel/begin revokes record/token before generator cleanup, and no frame-triggered compile fallback exists. Per-begin generation comes from an explicit generation value matching the zero-argument currentGeneration getter. Old generations and AbortSignal cancellation reject; new begin may capture a later generation. A modified source function remains unsupported until the approved source is restored/reloaded.

`withPrepared` is only a synchronous trusted controller bridge: it passes immutable model/clock and rechecks dependencies/residency afterwards, rejects reentry and Promise results. Callers must not retain model/clock after the callback. This dev factory is public, so an arbitrary external consumer is NOT authority; production must close the owner and bridge inside the genuine installed controller and reject external factories/models. No claim is made that unknown hostile callbacks cannot retain data.

Scope deliberately retains the old source75 source/FX/style/ghost/priority/mask/group/media exclusions. Circle center is restricted to top quarter (cy<=.25), single whole0..duration region,960×540/60fps/koma0; ordinary center(.5,.42) and two-row avoidance are unsupported. The sampler/collector enforce one row/2..7 glyphs. Font ID remains dela/face light/pips, original size/shape/text/delay. Negative/tail issuer range and normal UI post rendering remain later unqualified work. Unsupported/model miss must be wired to before-bitmap refusal by a future adapter/controller, not silently rendered as safe.

Serialized8MiB working accounting combines public/current and private plan snapshots, exact keys, font/source metadata and reference-slot/descriptor representations, clock/preimages/query bits/expected list, caller reservation, candidate/visual results, partial immutable model, current environment and simultaneous native/shift samples. Collector cached append bytes avoid whole-model serialization each own; current and commit accounting use immutable resident byte length. A fixed4096bytes reserves owner/generator/token/counter framing. Direct n-index clock assertion avoids future frame clock scans. Native Canvas backing store (2,073,600bytes while preparing, released on commit/cancel), encoder/native function/VM stack heap are outside serialized proof accounting; this is not JS heap/RSS8MiB. Shared/global actors require an actual reservation bridge when product-connected; only fixed explicit caller reservation is supported here.
