# Domino preparation stage 82t

Unregistered source-only adapter and local controller overlay. This unit intentionally cannot return a safe trajectory. It closes the first stage of actual adapter integration without claiming the completed owner/plan binding.

`create()` captures a private dense frozen native snapshot only from the real 09k adapter callback flags verified by 82s. It retains exact normalized input and font/generation metadata, including FontFaceSet and individual face identities. Text/region/normalized params changes replace the stage. Font revision/face/generation changes reject and discard the old stage; another explicit finalization may capture a new stage. No compile, paint, automatic re-finalization or model adoption occurs. The public factory/key is not authority.

The registered adapter deliberately throws DOMINO82T_PREPARE_REQUIRED. Actual 09k restores the original cut and attaches callback-owned runtimeAdmissionRequired diagnostics; its private runtime admission then rejects that failed plan before prior/decoded shortcuts. The controller overlay needs such a marker and rejects it at prepare before ctx/renderer/selector access or bitmap work. Unrelated adapters and intentional PRESERVED_LEGACY/no marker do not acquire this hook. Existing ticket path is otherwise byte-preserved except namespace.

Stage work has a 262144-byte local serialized cap under the unchanged 8MiB global proof cap. Input projection includes old stage reservations; stage snapshots, exact keys, fingerprint data, current work and face-reference slots are counted. It is not heap/RSS/Canvas accounting. There is no owner generation in this unit. A future integration must reserve this entire bounded stage amount in the genuine owner before preparing, and maintain simultaneous owner/model/frame/binding accounting; this unit alone does not establish that global integration.
