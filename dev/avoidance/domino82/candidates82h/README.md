# Domino upper-circle vertical candidate arithmetic82h

Experimental, unregistered candidate constructor. Dependencies: `dominoAffineSupport82c` and the existing `bulbsScalarCompiler80.serializedBytes` codec. Load those before `vertical-candidates82.js`.

Run `node candidate-test.cjs /path/to/82c/affine-support82.js`:984 checks, including BigInt exact-dyadic checks that every accepted synthetic candidate's ideal source-Y translation lies within Y stage and strictly below the circle. Tests also cover retained native X-outside bounds, signed zero, multiple positive root scales, sequence/missing clocks, two-row/domain rejection, typed insufficient space, zero supports, cancellation and8MiB refusal.

The caller supplies the complete clock-list in exact source schedule order; each sample must match the next `(n,pass)`, and finish rejects missing entries. The module does not independently prove that a supplied list is the native whole-clock list. The next compiler unit must derive it directly from the established clock/preimage enumerator and enforce exact coverage. No representative-frame substitution is allowed.

For one-row native samples under positive uniform root, aggregate conservative source-Y lower bounds for stage top and separation below the upper circle, and stage-bottom upper bounds. Candidate dy is input-derived `max(0,lower,below)`; there is no fixed109px offset. All support types enter these constraints, including glyphs and ground. Native X values are neither changed nor clamped, and no clip is introduced. Domain rejection is intentionally narrow: upper-half circle, one native row,2..7 native glyph count. This does not qualify ordinary circles or two-row avoidance.

This sufficient construction puts **all** support below the circle; insufficient vertical space is not global geometric impossibility. It can conservatively reject an input that could succeed through horizontal separation. Supports are potential enclosures, not actual paint counts. Even accepted candidates have `safetyAccepted:false`, `actualDestinationRequired:true` and `sourceXClipUnchangedClaim:false`. RootScale*dy is an ideal mathematical proposal only. Actual source-Y operation order, finite Canvas matrices, native-X bit equality, full Y/circle safety, source/clock/paint inventory and text quality require later actual all-clock acceptance. No certificate/owner/frame/UI path is installed.

Accounting includes cloned exact clock descriptors, circle, current scalar accumulator, current sample once per add, current support/work framing and caller reservation, capped at8MiB. Immutable current sample byte length is computed once per add; it is not reserialized for each support. Mutable accumulator/work are counted each update. Codec temporary heap, Canvas backing store and JS heap are outside this serialized working definition. The candidate output is counted before return; errors invalidate and clear clock references. Caller sample references are never retained after add. Full-clock timing and allocation costs are not measured by this pure unit.
