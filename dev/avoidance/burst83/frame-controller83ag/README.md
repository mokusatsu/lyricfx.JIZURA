Unregistered source-only prototype. Run `python3 run-tests.py /path/to/repository`.
The runner regenerates the two complete seams in a temporary directory, verifies their hashes, and runs 23 controller, 15 install, and 12 extracted bootstrap checks. Compiler, Canvas, dependency snapshot, and private issuer are mocked in controller tests; these are not actual Canvas or authority qualification.

The controller owns its preparation/proof owner and creates an immutable private publication. An external model, frozen alias, forged marker, or independently created owner cannot publish a genuine frame plan. Every selected pass receives current-context layout and geometry preflight before Renderer bitmap writes. Initial scope accepts only canonical `n/60` within reachable preimages (plus negative zero); negative, tail, and interior times remain unsupported. Generic trajectory/finalizer/cache/UI registration is absent. Existing sample-domain proof still declares `framePermission:false`.

Normal paint has no inspection/observer API. Source/Renderer installers must match protected original identities before consumption. Successful connection requires proof for active automatic Burst avoidance; failed installation both requires proof and blocks that target at the first Renderer statement. Manual/locked, no active region, and other layouts retain their route. A second controller cannot take over a successful connection. The protected accessors and monotone denial functions cannot grant drawing permission. Actual fake-first-install and bitmap refusal remain unverified.

Resident model/choice bytes are measured once after compilation. Publication bytes are measured once when the owner creates its frozen plan. Frames count small proof and selected-pass work, without serializing the whole resident model or compiling it. Mutable proof/work remains freshly counted; fixed additional control reservation is conservative. Combined actual peak and current-context allocation/performance require actual testing. Serialized bytes are not Canvas backing-store or process RSS limits.

Known constraints: preparation remains about 15 seconds in the prior sample-proof owner, not accepted for ordinary UI. Current-context local layout/metrics repeats in preflight and native drawing. No actual controller/plan/cache/UI result, all-continuous-time proof, cross-input safety, or practical preparation claim is made. Optional uninstalled 83ad normal-build regression is recorded separately; the additional protected bootstrap in this version still requires actual normal-build/controller validation before product integration.
