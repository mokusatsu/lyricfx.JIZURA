# Burst native scalar and star helper83a

Source-only extraction, unregistered in product HTML. No Canvas, layout/metrics, full-part descriptor, support, quality, candidate or runtime certificate is implemented by this unit.

The generator copies the native burst `out/q/rot/boil` expressions and star loop verbatim from the tracked11p source. It preserves arithmetic order and every RNG invocation, including nested r/rs/h calls. Motion remains time-dependent during held frames; it is not simplified to q=1. The star helper deliberately does not decide the board cull: its future caller must retain native ring/rays/debris before q<=.01, followed by the four stars and full text. Shadow and outer plate invoke the same k=1 star twice, as native source does; no memoization may erase those calls from fidelity comparison.

    python prepare-source.py /path/to/repository/src/11p_layoutsD.js

Run:

    node native-test.cjs /path/to/repository/src/11p_layoutsD.js /path/to/repository/src/01_util.js
