# Fresh no-paint whole-clock comparison83r

The unregistered compiler83q / sampler83n produced a fresh model on one dedicated harness Canvas. The host compared it with the existing 83m actual-paint oracle. No new paint was performed. This remains a source-only, non-authority model at sampled times for the limited JA input; it is not a continuous-time, private runtime owner, finalizer or UI certificate.

Additional saved-data comparisons can be rerun with:

```sh
node dev/avoidance/burst83/wholeclock83r/reanalyze.cjs /path/to/burst-compiler83r-actual01 /path/to/burst-default-destination83m-actual01
```

The script verifies compressed and decoded hashes before comparing scalar, native/half sizes, half diagnostics, own clock and glyph seed. Raw stays outside Git. The independent full geometry check is described in the repository review record; this short checker does not replace it. The proof cap is 8 MiB serialized accounting, distinct from Canvas backing memory and JavaScript heap. Measured preparation remains unsuitable for an unqualified practical UI claim.
