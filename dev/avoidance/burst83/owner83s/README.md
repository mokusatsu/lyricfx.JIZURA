This unregistered owner invokes compiler83q internally on its own dense, frozen plan copy and a fresh dedicated Canvas. Public factory instances and opaque handles do not confer renderer or finalizer authority. No saved raw is accepted as model input. A job exposes progress and a ready handle/counts, never its context or model. Only one building job or resident model is allowed per owner.

```sh
python dev/avoidance/burst83/owner83s/run-tests.py /path/to/repository
```

The 62 checks use the real tracked codec and explicit compiler/DOM/dependency snapshot test doubles. They verify copied nested ownership and -0/undefined preservation, normal ready/validate/drop, cancellation, input/revision/generation invalidation, setup failure cleanup and subsequent start, dense-data rejection, and generation/Proxy reentry rejection. The test-only native DOM replacements are not evidence of native setters or Canvas behavior. Real Canvas owner testing is next. Compiler83q's separate whole-clock Canvas comparison is not this owner's qualification.

Start, validate, drop, cancel and step are synchronous and exclude reentry. Generation callbacks receive no arguments and must return true synchronously. The plan's original data key and dependency snapshot are rechecked across resumes and ready-handle validation. Undefined values are retained as explicit values with the codec's separate token; functions, symbols, accessors, sparse/custom arrays, cycles and unsupported prototypes are rejected. The owner does not trust foreign frozen identities as private input. Mutation of the original input invalidates the job/handle.

All Canvas setup after creation is within owner-local failure cleanup. Cancellation/drop/failed validation remove authority-bearing entries, shrink the surface and release captured model/plan/dependency/generator references. Native surface disposal failure handling is not qualified beyond the current source-only tests. The ready surface is retained until drop: 960x540 RGBA would be 2,073,600 backing bytes before browser-specific overhead; this is separate from serialized accounting and RSS.

The unchanged 8 MiB serialized limit combines caller reservation, original/private plan data and signature, delta, dependency values/reference slots, fixed owner/control reservation (4096 bytes), compiler tables and transient sampler/entry work. One-entry ownership avoids simultaneous old/new model retention. Actual whole-clock peak and preparation/heartbeat must be measured for this owner before any practical or UI claim. The 83r low-level generator's 6.84 second result is not a practical UI acceptance.
