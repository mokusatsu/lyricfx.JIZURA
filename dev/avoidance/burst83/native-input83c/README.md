# Burst current native input accessor83c

Source-only, uninstalled extraction of the original burst native layout, size, scalar and palette inputs. The original renderer body is byte-identical after removing the inserted fragment. The generated full source stays outside Git; run-pure.py regenerates it in a temporary directory and checks the fragment, zero-context diff and boundary bytes.

Run `python3 run-pure.py /path/to/repository`. After repository installation the root argument is optional. Dependencies are the tracked src/11p_layoutsD.js, src/01_util.js, src/02_fonts.js, src/03_text.js and preceding native83a/native-parts83b modules. No external raw, fonts or absolute evidence paths are required.

The 2,400-case comparison passed 24,002 checks with synthetic measurement. The same cases passed 24,015 checks using the actual metrics, layoutText, measure and fitSize source with synthetic fontCSS/measureText. Both use synthetic segmentation, registration, primitive drawing and test-only private-cache inspection. Native and descriptor calls, order, values and final color-cache contents agree across portrait/landscape, Japanese/Latin strings, palettes, temporal states and cache histories. These are pure numeric/source tests, not Canvas/font/raster or avoidance qualification.

The palette peek reads existing onCol hits, including historically stale values because the native key excludes sub. On misses it computes the original choice without set or clear. Tests include empty cache, 300/301 entries, truthy and empty-string hits, duplicate keys/colors and invalid color strings. The accessor does not expose the private Map. The native renderer retains its original cache write/clear behavior.

This accessor is not completely free of side effects. fitSize calls measure/layoutText; both fitSize and the final measure invoke metrics.adv. On a miss, the original metrics implementation assigns the dedicated _mc.font, calls measureText and stores the advance. Hits reuse it. clear empties the Map and increments revision; reads/additions do not increment revision. loadingdone and font registration can clear metrics. The accessor neither measures through env.ctx nor owns immutable inputs: source.params remains the original reference. No persistent result may be treated as a certificate. Actual loaded font faces, CSS, metric-context state, revision drift and source/helper identity still require guarded Canvas comparison before model/owner adoption.

No recipe, support enclosure, quality proof, all-clock coverage, cache admission, runtime authority, product registration or UI performance claim is supplied by this unit. The next gate must compare native current-input layout/metrics/colors and source calls on the same runtime and preserve font/revision invalidation.
