## Remaining product boundary

The tested numeric viewport is640, and fast/noPost is required. Other viewports, input/font/circle changes after fresh reprepare, ordinary normal-post, performance, and direct main UI installation are unqualified. Viewport is factory-owned immutable configuration; a later mutable-viewport/session policy requires its own invalidate/reprepare design. The existing bulbs coordinator can be reused as an outer generation/cancel/error interface after a runtime facade maps these methods, but its ordinary main drawing requests normal-post and cannot be silently redirected to this restricted route. Factories/handles/certificates from bulbs and old83ax are not interchangeable. Sticky cleanup/error behavior must remain in that future outer facade. No claim of arbitrary shared-renderer exception-stack recovery follows from the two controlled prefix tests.
