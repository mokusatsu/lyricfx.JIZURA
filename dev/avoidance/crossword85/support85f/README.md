# Crossword fresh supports85f

Unregistered nonpainting sampler for the current58A family. It reuses84f's plain actual glyph/font/ink calculation and outward affine support, adding rects and single butt/miter lines. It preserves mainDraw's integer-mi stagger gate for cut entrance, ghostfalse omissions, metadata, full glyph order, actual CTM and line-width readback. Cut/still/cut/no-treatment,960×540/scale1,≤7nonspace glyphs and dela/body-gothic_med/mono are the limited profile; unsupported values throw. No owner/certificate/frame authority is issued.

`sample(env,{reservedBytes,deviceDelta})` counts caller reservation, source input/program, current layouts and custom layout properties, append outputs/glyph metadata, transient work and result copies inside8MiB serialized. Surfaces and process heap are separate. The context must be dedicated and satisfy native default attributes plus native zero-spacing readback; the public sampler/factory does not establish this ownership. Future owner/controller dependencies and closed provenance are still required. No frame-time compilation is installed.

Run `python dev/avoidance/crossword85/support85f/run-tests.py /path/to/repository`:16 synthetic Canvas/layout/request checks with actual codec/affine, covering normal/ghost/stagger, shift/restore, capacity, bad metrics and unsupported profile. These are not actual-font proofs.

Actual85g uses fresh input/context for3own at t1 and matches existing85d141 paints (14rect/74line/53glyph), including font/ink/CTM/args/alpha/color/line states; bitmap before/after unchanged and pristine. Parent independently verified raw hashes and the564 Fraction containment checks. Peak1,866,704B, revision4; no original frames rerendered. The optional checker requires external raw: `python dev/avoidance/crossword85/support85f/fraction-check.py /path/to/crossword-support85g-actual01 /path/to/crossword-family85d-actual01`. It uses actual paint state/metrics/paths,1fontpx glyph margin and2devicepx raster premise. The initial checker misnamed path.key as kind, then was corrected without drawing. This one-held envelope is not all-time, circle/placement, quality, owner, plan or UI qualification.
