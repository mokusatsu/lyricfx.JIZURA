# Crossword native source85a

Unregistered source-only extraction of the current native crossword topology and full ordered source requests. Run from any directory:

```sh
python dev/avoidance/crossword85/native85a/run-tests.py /path/to/repository
```

The runner verifies hashes, regenerates in an isolated temporary directory, compares generated bytes, and runs4033 checks across720 synthetic states /37544 source requests. The reference is the full current layoutsD registration, with real utility RNG/color/easing. Both branches use the same synthetic chunking/romaji, draw recorder and nominal mainDraw boxes; fonts, glyph transforms, actual paint/support/AA, candidate safety, owner and UI are unqualified. Empty text returns null; the initial test incorrectly read its n field, then was corrected to the existing null behavior (failed test preserved outside Git).

`layout(env)` returns fresh source-derived grid/lyric rows, end caps, symmetric black cells, numbering, pencil entries and sizing. `render(env)` runs the literal native source against the supplied env. Neither grants authority. Private helper caches are not returned; calls may populate the extracted helper's private pool cache. Actual source/Canvas/cache behavior still needs independent comparison.

The approved58A strategy is distinct: cell scales by0.58, numbering and clue sizes remain based on native cell, lyric cell text uses0.65 instead of native0.7, and clues move below. These approved semantic choices are future candidate parameters, not a fixed text/seed/delta branch. Every grid background/black/highlight cell, line, number, crossing glyph, full lyric and four clue lines must be retained. Input-derived placement/support/unsupported handling is not implemented here.
