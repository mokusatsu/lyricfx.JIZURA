# Crossword sampled j/60 semantic union85k

Unregistered compiler. It uses an owned dense null-prototype/deep-frozen copy of current input, fixed960×540/fps60/duration4.150001/push camera and the existing private-context sampler85f profile. Each active selected pass is sampled at state.n/60 as actual realTime, not state.firstTime. Preimage data is clock provenance only; this does not certify continuous time. A caller must own the context and validate input/generation/fonts/source dependencies before and after each own and publication. Public callbacks/results are not authority.

Semantic keys preserve primitive source positions/kinds, full item text/font/size/layout values, main typing mi, glyph index and character. Rect height varies with source clocks, so its union uses a stable source x/y/width key; line geometry and glyph identity are retained. Merging only enlarges supports and cannot remove a sampled bound. Results carry source metadata and no frame permission. Cell/number/pencil/clue quality and actual wholeclock paint correspondence remain independent. The finite58A proposal may return explicit unsupported; that is not an impossibility proof.

The8MiB serialized account includes caller/original+owned input/key/full clock, private semantic keys/data/unions/map keys+96Bslots, current complete sample/work/proposal/copies. Native surfaces/heap are separate. Exact entry-array bytes use append framing and immutable key data plus mutable finite-F64 bounds/count fields (constant encoded width); normal mode checks the full entry byte count once before publication. The mock test instruments every private account to compare against full serialization,9492 audits, without adding this overhead to normal compilation. Current sample bytes are measured once per own, not per primitive. Diagnostic detail copies must be reserved by a retaining caller. Cancellation/stale/budget failure discards partial entries/Map; caller owns native surface cleanup.
