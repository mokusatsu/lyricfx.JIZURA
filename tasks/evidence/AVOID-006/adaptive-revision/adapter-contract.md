# AVOID-006 adaptive native-source adapter contract

This is the opt-in revision of the previously reviewed joint-translation adapter. `J.finalizePlacementPlan(plan,{layoutsA:true,layoutsAAdaptive:true})` enables the reusable registry for justified, subtitleBar, splitScreen, sideways, panels, filmstrip, quote and ticket. The other18 and every existing native-safe segment retain their prior drawing and placement. Main-app activation remains017. There is no automatic fallback implementation in this revision.

`J.placement.compositionStrategies` holds bounded, ordered native recipe factories. `registerCompositionStrategy` and `planAdaptiveComposition` are reusable infrastructure; registration alone does not prove another layout safe. The exact current orders are in `dev/avoidance/contract.json` and the source-backed inventory. Each candidate retains full-stage W/H, original cuts, source text/chunks, seed, clocks and painter roles. No whole-stage bitmap is fitted into a local rectangle. Local owned plate/frame dimensions, wrapping, spacing, centers and explicitly bounded native path parameters may change.

## Selection and quality

Existing full native certificates win without new floors or changes. An insufficient native segment first tries moving-event-only entrance/exit relaxation. Native-size local recipes precede discrete reduction .95/.9/.85/.8/.75/.7. Every actual recipe is checked over the full interval before the same recipe's eligible motion events may relax. Hard failures reject the candidate before selection: unsupported measurement, incomplete source-copy ranges, lost meaningful metadata, un-clipped text outside its owning shape, reconstructed size below floor, invalid fixed contrast/picture field, or insufficient geometry.

Auto primary floor is max(18px,.035U); meaningful secondary floor max(12px,.020U), U=min(W,H), measured after contentScale. Existing native-safe text below these limits is preserved. A native primary already below its floor cannot shrink further. Explicit lyric notation size and real project `lyricCutOptions[line:part].details.contentScale` prohibit additional reduction; same-size reconstruction is permitted where existing area/lock priorities allow it. Manual/notation areas, OFF, emphasis and lock retain their previous behavior. Subtitle huge copy remains at least1.5 times native subtitle size; only the huge-copy role reduces.

`composition.glyphCoverage` contains observed ordered grapheme ranges separately for every actual copy: main, huge/subtitle, or off/on complementary split copies. Source coverage cannot be satisfied by auxiliary or metadata text. Meaningful metadata text/font/count is separately compared to the native preparation. `composition.quality` records actual fonts/stage sizes, floors, font scales, spacing/wrap/shape/path changes, pre-clip owning-shape tests and metadata coverage. A clipped fragment cannot stand in for a complete glyph.

Justified retains native filler coordinates and attached No/row-count captions. Split retains the stationary two-color field and complementary world-fixed clips, including metadata's correct half after solved displacement. Subtitle retains native picture/letterbox/UI and verifies huge-copy ink against the opaque picture field before and after displacement. Sideways keeps the native rotated main and horizontal companion. Panels retain stage-derived reading axis and original chunk font hierarchy/wipe/focus. Film retains continuous holes/slots/countdowns/codes and native phase; every lyric/countdown's full ink fits its frame. Only native edge-code along-axis stage cropping is preserved, with all code geometry still circle-tested. Ticket retains one attached shape, aspect[1.8,2.8], header/body/footer and stub zones, perforation/barcode/serial and native tilt/tear clocks. Quote retains body/attribution/mark structure and source easing.

## Continuous geometry and event phases

Candidate full envelopes include native geometric sweeps, contentScale/camera/FX and AA bounds from the existing adapter. Each actual convex primitive must fit one stored convex envelope. Full `safe` and `certified-bounded-adapter` mean the whole interval is strict. `safe-hold` and `certified-hold-adapter` mean stationary events are always strict and only source-tagged geometrically moving entrance/exit events may cross temporarily. They never mean all-time clearance.

Motion phases use each pass's native motionTime. RealTime independently selects the region. The actual event tags and entry-completion times are film-strip .6s, quote-marks .52s, ticket-body/stub .5s, side-companion .65s. Other events are always strict, including quote body/attribution and fading/revealing text. Exit begins at cut.end-cut.outDur only where that event actually moves; a zero-tilt ticket body fade remains strict. Hold intersection must last at least.04s. Short/no-hold intervals are rejected rather than relabelled entrance forever. Persistent film drift stays strict and its ltb range includes maximum ghost lag1.6/24 plus two quantization steps on either side. This envelope expansion does not enlarge relaxation windows.

`segment.envelopes` is the selected strict proof, with actual `from`/`to`. Reconstructed held candidates additionally carry `segment.relaxedEnvelopes`, the full reconstructed motion proof. Native held candidates use original native full envelopes for relaxed events. Runtime observations expose `strictPolygons`, `relaxedPolygons`, actual event motion/phase, realTime/motionTime/pass, holdWindow, strict/raw clearance and scope. Independent oracles must not test a new recipe using the old native unit envelope.

## Budgets, failure and lifecycle

At most64 reconstructed candidates per region and128 unique recipes per cut are considered. Up to eight area-ordered outer-band/circle-chord measures are considered for each declared geometry strategy/scale. First passing candidate wins; there is no unconstrained score search. Measurements omit prior trajectory/attempts/region proofs from cache keys. Existing preparation LRU capacity2048/64MiB and solver8192/8MiB remain bounded. Adaptive candidates use direct recording rather than filling that shared LRU with rejected draw programs. A separate exact-input decision/proof cache is bounded by4096 values,1024 interned source contexts and8MiB of encoded retained data. Context keys include source, explicit-size provenance, font revision/language, W/H, style/FX/fps/duration, events, evaluation range; candidate keys include geometry/circle and hold-intersection eligibility where relevant. Quality failures and full-interval successes are independent of hold intersection and share their key. Budget accounting still happens before any cache lookup, preserving strategy order/counts. No per-glyph stage buffers are introduced. Earlier chronological regions can consume the unique budget; later failures record CUT_CANDIDATE_BUDGET and do not claim all strategies were tested. Selection is finalized once, so seeking cannot change it.

Failure marks `decision:excluded-during-avoidance`, `failure:no-certified-composition`, retaining the original lyric-bearing cut and honest insufficient status. `compositionEligibility(plan,cutIndex,time)` reports actual eligibility, decision, failure and provenance. Fallback is only eligible with source-proven automatic selection and compatible priorities; `fallbackSelected` remains false. Explicit layout reconstruction does not authorize another ID. No blank rendering or deletion is a fallback.

Refinalization removes stale derived compositions/trajectories before rebuilding, with source/font/options signatures kept separately. New source/font revisions are remeasured. The fixture's `observationAt(time,observations)` resolves the real segment and eligibility on each seek; excluded segments have no selected strategy. Pixel auditing uses fresh makeEnv closures and original source FX before motionScale, preventing double damping or missed owned plates.

## Meaning-preserving performance changes

Candidate proof polygons are privately encoded as Float64 coordinates plus Uint32 polygon lengths. Every numeric bit, including signed zero, is retained. Private buffers never escape; reads decode into owned deeply frozen ordinary arrays. Other retained data is JSON text. `adaptiveCacheStats().serializedBytes` counts actual buffer.byteLength plus retained context/key/JSON UTF16 bytes; it is an encoded data limit, not a measurement of JavaScript heap. The three strong value-cache data limits total80MiB (64+8+8); object/Map overhead and the composed plan itself are separate. Explicit replacement and eviction subtract old byte/entry counts. Font revision invalidates values; source/region/explicit-size/event differences cannot reuse another proof.

The solver reuses support/offset calculations only for exact equal normals, distinguishing signed zero. It still pushes every original candidate in the original order, preserving the final offset Map's winner and signed zeros. Rounded-rectangle measurement uses the same32 angular samples, selecting the same exposed extreme points from the original128-point union via corner support cones; actual numeric min/max corners handle collapsed-center rounding. Circle32/64 trig tables reuse the exact prior values and invalidate on TAU change. Radius, outer polygon precision, stroke and one-device-pixel AA padding do not change.

Runtime coverage subtracts an offset once per actual polygon. It tries envelopes whose bbox contains that polygon's first vertex before the remaining envelopes, retaining the exact inside predicate/epsilon and every fallback candidate. This is ordering only, with no broad-phase rejection. The WeakMap of envelope bbox views is tied to the lifetime of the finalized frozen envelope arrays; it does not strongly retain abandoned plans or contain independent drawing buffers. Full-interval raw clearance reuses strict clearance when the sets are identical.

Codec, exact signed-zero solver, exact AA/affine shape and epsilon-boundary coverage equivalence are separate checks from actual PNG/render tests. Performance failure history remains recorded; only the final same-input measured gate can authorize performance acceptance.
