# AVOID-006 native MP4 visual review B

対象: `work/all006-native-mp4/local-20261021-03/manifest.json` の後半13演出、before/afterの計26動画。レビュー担当は製品・toolsを変更していない。

結論: 今回実見したアンカーおよび抽出時刻では、afterに新たな文字欠け、文字化け、演出消失、HTML操作UI混入、全区間の不自然な静止を疑う差分は見つからなかった。これは指定サンプルの画像照合であり、全フレーム検査・連続再生による合格判定ではない。

実見範囲:

- 全13演出のbefore/after PNGアンカー計26枚を`view_image(detail=original)`で個別表示した。
- 各動画のフレーム0/3/15/36/90/95をffmpegで原寸PNGに抽出した。24fpsの対応時刻は0/.125/.625/1.5/3.75/3.958333秒。抽出計156枚を全13枚の比較montageで実見した。montageは各セル最大640pxへ縮小し、ツール表示でも全体が縮小された。したがって156枚すべてを個別の原寸表示で確認したとは主張しない。
- filmstripについては抽出12枚も原寸指定で個別表示した。
- 連続再生は担当範囲外。サンプル間で起こる一時的な異常、精密な円との接触量、完全な時間的滑らかさは本レビュー単独では証明しない。円ガイドはnative Canvasに含まれないため、円回避の数値認証は別途診断証拠との照合が必要。
