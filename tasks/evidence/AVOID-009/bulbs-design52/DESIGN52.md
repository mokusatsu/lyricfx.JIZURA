## What arrangement must preserve

All sign-owned face/shadow/outline, every current ring/N/i bulb including dark bulbs, halo/glint, main lyric and subtitle remain PRIMARY under one common stage translation. No mask, auxiliary reclassification, ring removal, extra caption truncation, lifetime shortening or new timer is a solution. The first unchanged-sign translation stage keeps native font sizes; later non-explicit font downsizing is allowed in principle as a distinct typography strategy with a readability floor and source-structure review. The source has no sockets/wires/SCORE to invent. Main text is not multiplied by out; subtitle has its own fade. Common placement means T(delta) M_p nativeBody, not adding the same numbers to cx/cy before camera. Original ownership/callback order remains; source q is not converted into a uniform Canvas scale.

Changing the target circle should not require rebuilding font or native geometry templates. Circle inputs are original-stage cx/cy in[0,1], radius in[.02,.45], with C=(cx*W,cy*H), R=radius*min(W,H), margin=max(2,.005min(W,H)); contact is a conflict. Regions are half-open realTime intervals, fixed circle within each region, gaps mean no circle, overlap is rejected. One common placement over all relevant regions avoids new jumps; independently switching positions at region boundaries would be a separate motion design. A future continuously moving circle is outside the current contract and requires a separate circle-motion enclosure.

Strategy is not an unconditional move→split→shrink ladder. First preserve zero offset if it satisfies all obligations. Whole-sign translation should be the first meaningful comparison where an original-size sign can plausibly fit: it preserves arrow/double, asymmetric q responses, N(t), i/N, lighting and one readable marquee. Derive feasible stage delta bounds before enumerating a large grid, then evaluate circle constraints without confusing an outer-envelope rejection with actual collision. Prefer source-stable direction choices according to circle position; do not ban other directions.

For very long/wide signs, cheaply established extent obstructions can justify examining original-font reflow/aspect changes before excessive translation search. Reflow changes board/inset perimeter and therefore native N/phase; preserving the old ring/N/i arc fractions on a new outline preserves cadence better but changes spacing and possibly halo/text separation. Recomputing N for a new perimeter changes counts and phase. Either is a visible redesign needing explicit kinematic/readability review. Limited pad adjustments can sometimes be less disruptive than reflow, but must retain caption space, source halo/outline clearance and both rings/tip. Splitting destroys one circulating marquee and caption unity; it is a new design, not a default fallback. Shrinking explicit sizes or the entire effect into a miniature rectangle is forbidden. Non-explicit local font/dimension redesign requires a readability floor and separate review. If none is justified, return unsupported/insufficient proof/space for that scope without deleting content.

## Exact source branch ledger

Let tau=env.lt, D=cut.dur, d=cut.outDur. Source p=clamp((tau-(D-d))/d) when d>0, otherwise0; x=clamp(tau/.35). The literal Float64 code computes out=1-inCubic(p), q=outBack(x,1.4)*(1-.1*inCubic(p)). In ideal real arithmetic B(x)=1+2.4(x-1)^3+1.4(x-1)^2. For a nonoverlapping4s cut B first reaches1 at tau7/48, peaks at77/360 with value1+343/4860, then reaches/stays1 at.35 until exit. Exit q ends at.9, not0; out ends at0 and the source disappears. These are algebraic landmarks, not exact Float64 branch times. Short cuts need the full overlapping product and new extrema; outDur0 has no artificial fade/exit shrink. q<=.01 or out<=0 culls the entire sign by source rule.

Main body source: env W/H can differ from original stage under manual area; port is strictly H>1.08W. Board/double is the original24-vertex straight polygon, arrow seven vertices with .42bh center correction and .5bh tip. Shadow adds (.012u,.016u) after q. Outline remains the original repeated-first-vertex open polyline, miter join/butt caps, actual miterLimit/dash/stroke width; it is not closePath or half-width-only support. r=clamp(.075size,4,.022u) is not scaled by q. Main glyph size is size*min(1,q) with an independent anchor; subtitle is min(ss*min(1,q),original fit), at its original fixed anchor, preserving exact UTF16 source truncation and body font.

For each ring k, use actual inset vertices and original resample output. N=max(4,min(140,round(L/(3.3r)))) is recomputed every render from the actual Float64 hypot/sum chain. Ideal L(q)=qL(1) is useful algebra, not a boundary proof for Number operations. N changes alter i/N, every sample point, on0 and phase. Ownership is ring/currentN/i, not a static lifetime bulb list. SOURCE50 observed N4..136, not140. Source resample walks while acc+seg[si]<target, a strict comparison; zero-length edges and rounded ties need explicit enclosure or unsupported classification.

Chase uses j=(i*dir+4N)%N and floor(ltb*9); alt uses floor(ltb*3); wave uses the literal sine/pow expression; on0 and beat.since<.12 can force lit1. Initial support can conservatively include all positive paint, including below1/255, so it need not use a new alpha cutoff. ## Continuous support: rigorous structure versus open numeric admission

The easiest continuous ring bound does not enumerate fixed N. In ideal real arithmetic each resampled center lies on an inset segment, so union over the closed inset outline plus a2.1r disk encloses all ring states and possible halo/glint/base support regardless of N/lighting. For actual Float64 code this requires a directed bound on computed f and lerp residual: a rounded acc+seg comparison can permit a near-endpoint f slightly above1. Include both adjacent endpoint/edge enclosures and that quantified residual, or keep this bound conditional; do not assert exact convex interpolation merely from the ideal formula. Glint offset norm plus .35r is below2.1r. Under general affine camera, transform the local disk correctly as an ellipse or a proven enclosing rectangle; do not add an unscaled radius after arbitrary camera/skew. This envelope preserves actual count/cadence and may overreject. If it blocks a potentially useful candidate, refine fixed-N/edge-selection cells with directed source-ordered evaluation. Do not silently remove dark bulbs or assume samples have proved the N range.

Body polygons include interiors/edges, not only vertices. Shadow uses a separately translated polygon; stroke requires miter support using actual state. Main text/subtitle require actual ink metrics at each reachable CSS font/string/language/face/baseline, glyph transforms, stroke and AA. Maximum-size metrics scaled down are not a proof. For true continuous own-clock q, cover every reachable fontCSS toFixed(2) string (including rounded boundary neighbors) and separately bound native positions/size-dependent advances. A finite-clock model instead needs only its complete reachable actual CSS states. Font loaded-face/revision/real Canvas state belongs to admission, not fixture seed.

Continuous mathematical cells must split at source clamps, q=.01/q=1, extrema, p0/1, .35/.6, caption fade/fit/size gates, font bins, source hold/step/ghost branches and camera knots. Fixed-N refinements additionally split count ties, resample edge selections, on0 inequalities, chase/alt/wave and beat boundaries. Use literal Float64 source operation order with directed arithmetic, retaining uncertainty at ties; exact real cubic roots alone do not prove source Number intervals. No inherited magnets128/tiles512 blanket Canvas/libm guard is available. SOURCE51's M-prime measurement and native M remain different facts. Until an actual root/local-paint numeric admission is established, this continuous ledger is explicitly CONDITIONAL_NUMERICAL_DIAGNOSTIC, not certificate.
