First try strict stage inclusion for complete guarded geometry throughout. Native negative launch and .7H exit often make that impossible despite a valid held arrangement. Do not shorten native travel to satisfy blanket strict stage.

A narrowly source-led stage policy could distinguish (1) native TOP ingress while actual original fall0<=f<1, (2) fully stage-contained ordinary/held states, (3) native BOTTOM egress while the original exit component genuinely moves, and (4) a complete bottom-exited tail. Entry/egress acceptance would need source-owner/pass/part evidence, complete geometry and exact expiry, independent of circle policy. No SIDE crossing or floor relaxation follows. A moving phase that is still stage-internal is checked normally, and bounds on un-clipped geometry remain recorded. For q1 stationary tail, a possible separate rule is ONLY after proved original moving egress and ONLY if that owner's complete guarded polygons (every relevant active part/copy) are already disjoint below stage, with a finite native engine emission expiry. Record wholly-exited bottom support, no re-entry over all native bounce/hop/camera bounds, and expiry from actual cut/display/ghost source membership. Original face alpha expiration and glyph engine expiration must be distinct. Circle remains strict for stationary tails; complete stage exit does not silently broaden circle allowance. This is a proposed policy for review, not an already accepted exemption.
