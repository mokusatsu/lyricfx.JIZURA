# 独立ローカル画像照合

判定：閲覧した16枚の範囲では、全面敷き詰めと主カードの中央回避は成立している。目視で修正必須の欠け・遮蔽・不自然な紙比率は見つからなかった。これは静止サンプルの判定であり、動画全体の認定ではない。

## 対象・方法

提供された before / after の各フレーム 0 / 8 / 15 / 22 / 40 / 90 / 117 / 228、計16PNGを view_image の original で閲覧した。画像は960×540。親から指定されたnative 60fps・4秒の同時刻比較として扱ったが、動画・メタデータからの独立検証は行っていない。ユーザー添付画像はこのコンテキストに存在せず、参照していない。

## 観察

- フレーム0は両方とも暗い背景のみ。開始時の未表示状態が一致し、この1枚については敷き詰めの成否を判定できない。
- フレーム8以降、before は中央の4列×3行と広い左右余白。after は上下左右の画面端まで規則的なカード面が連続し、外側4枚だけを足した構成には見えない。上下端にはカードの細い切片、左右端には裏カードの一部が見える。これは指定どおりの意図された端のcropとして扱った。
- after の紙の縦横比・列と行のピッチは整っている。閉じ札はおおむね同じ大きさで、before の紙と視覚上同じ比率。元の隙間に相当する細い暗色の列間・行間は残り、大きな空白帯や欠落したセルは見当たらない。めくり途中に紙が細くなった位置の暗い領域は、対応するbeforeにも存在する回転の見え方。
- フレーム15では最初の札が裏面のまま回転中、22では「風」が開いて次の札が回転中、40では「風」「の」「先」が開いて「へ」がほぼ横向き、90/117では4枚とも開く。228では左側から閉じ戻る状態。before / after の各同時刻で、主4枚の面の状態と文字の順序は視覚的に整合する。
- after の主4枚は同じ中央行の左2枚・右2枚となり、「風」「の」と「先」「へ」が左右へ離れる。指定円 center=(480,226.8), r=108 に照らすと、主4枚は円の左右外に配置され、閲覧サンプルでは円内へ侵入しない。閉じ札と上段の「?」が円領域に残ることは指定上許容された要素として扱った。円そのものは画像に描かれていない。
- 開いた主札の大きな文字・橙色の隅文字は紙面に付着して見える。フレーム22、40、90、117、228の見える文字に画面端による欠けはない。40の「へ」等の細さは紙の回転に伴う遠近変形としてbeforeと整合する。裏札や影で主文字が不自然に隠れる例は、閲覧したサンプルでは確認しなかった。
- 上段の「?」は90で回転途中、117で正面。afterでは中央付近の上段へ移っているが、紙面から外れたり欠けたりしていない。

## 制限・人間による追加確認

16PNGのみを閲覧した。全240フレーム、動画の滑らかさ、瞬間的なちらつき、サンプル間の文字欠け・影の重なり、開閉の連続的なテンポは確認していないため、人間が動画再生で確認する必要がある。2pass描画の実装、sourceflipの時計・順序の完全一致、font .9設定の保持はソース未閲覧のため認定できない。静止画上は順序・文字サイズ感・影と文字の見え方に目立つ破綻がない、という限定的な所見である。

ソース修正、browser、ネットワーク、公開URL/HTTP/公開hash照合、動画閲覧、起動、status polling、Git、cleanupは実施していない。public checks=0。ローカルPNGのSHA-256は receipt.json に記録した。
