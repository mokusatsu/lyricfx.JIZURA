## 1. tilesの主要な調査結果

タイル上の点数は、下部SCORE表示と独立して描かれる。`score=false`でも、`pts>0`のタイル数字は残る。主文字だけでなく、面・厚み・上端ハイライト・数字・ラック背面・投影影・前縁・前縁線・SCOREと総得点を所有物として記録する。〔`src/11p_layoutsD.js:1536–1577`〕

タイルと主文字の変換は完全に同一ではない。leanの回転前後の適用差と、主文字だけが通るmainDrawのenter/hold/exit/treatを保つ必要がある。さらに入場は元の通し番号i、退出は元の行内番号j/cntに依存するため、行分割の変更と時間順の変更を切り離す。〔同:1544–1567〕

推奨は、ラック単位の共同配置を軸に、dropでは縦経路、slideでは横経路を含めて空き帯を選ぶこと。短文ではラックの連続性を保つpitch・余白調整、長文では原寸の連続語群の再配分を比較する。落下後の跳ねには明示的な打切り時刻がないため、着地後も元の描画寿命内で包絡して判定する。

## 2. bulbsの主要な調査結果

電球の個数は時間で変わる。拡大後の輪郭を`resample(inset(k), r*3.3, 140)`で再分割し、輪郭長に応じて4～140個の電球を生成する。元の電球半径は看板の拡大率qへ比例せず、個数Nの変更は`i/N`を使う点灯順にも影響する。固定数の電球を剛体拡大するモデルでは元描画を再現できない。〔`src/11p_layoutsD.js:1584–1595,1647–1668`〕

看板のovershoot、主文字の字号`size·min(1,q)`、字幕の字号・基準位置、影offset、電球radiusは別の規則で動く。haloはぼかしではなく半径`2.1r`の円であり、消灯中にも電球本体は残る。〔同:1629,1641–1648,1666–1677〕

推奨は、まず全所有物を保つ共同stage移動、その後に文字と字幕の書字領域を保つ看板縦横比・余白の再設計を比較すること。輪郭を変える案では、元の電球数・点灯順をどのように保存するかを独立した条件にする。看板の分割を既定fallbackにしない。

## 3. billboardの主要な調査結果

支柱と筋交いは、動く看板下端から固定の`groundY=.94H`まで伸びる。看板面だけを移動すると接続が壊れ、全構成を一律に上下移動すると地面との接触が壊れる。足場の床・11本の縦部材・手すり、灯具と接続材も含めて扱う。〔`src/11p_layoutsD.js:1790–1807,1836–1841`〕

照明は看板面にclipされたradial gradientの多角形と、面全体への別の明るさ重ね描きから成る。両者は同じalpha式ではない。照明の省略や、看板だけの外接矩形による判定で成功扱いにできない。No.と時刻表示も看板所有のmetadataである。〔同:1820–1834,1845–1848〕

推奨は、地面の基準を固定したまま看板・支持構造の配置を共同で設計し、必要に応じて書字領域・看板縦横比・支柱位置・筋交いの形を比較すること。照明の専用記録・再生能力に不足がある場合は、限定した対応案として共有基盤の担当へ戻す。

## 4. 全区間安全性の扱い

判定は、現在の円と、各passの元時刻で描かれる全所有物を対応させる。全区間の厳密条件は`dist(C,P)>R+max(2,.005·min(W,H))`であり、接触は衝突である。〔`dev/avoidance/contract.json:26–31`〕
