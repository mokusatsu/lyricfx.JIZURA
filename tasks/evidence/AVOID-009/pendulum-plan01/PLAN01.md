## Original clocks, gates and identities

Build an immutable native catalog BEFORE any candidate changes. Store original object i/k/n and native lengths/periods; geometry candidates must not become clock input.

Cradle exact formulae: r=min(.84W/(2.02n+1.2),.13H,.12min(W,H)); L=min(.42H,5.2r); py=H/2-.62L; px=W/2-(n-1)r+2ir. t0=.75; tau=ltb-.75; sAng=tau>0?-cos(2πtau/period):-1; lift=tau>0?1:inOutCubic(clamp((lt-.25)/.45)); decay=1-.25clamp(tau/6). Angle uses original endpoint index branches, special n=1 branch, native amp*(.6+.5motion), min/max of sAng. drop=outBack(clamp((lt-.05i)/.35),1.4), Lc=L*drop; drop<=0 omits the entire bob and its strings/text. Preserve miAt(.15+.05i), out/gIn, spark modulo/near<.08 predicates and spark q=-1,0,1. Do not make sparkle detection depend on new spacing or object traversal.

Fan/chunks: original items count k; native fan step=min(.84H/(k+1.2),.2W), size=.84step, L0=1.4step. Chunks size uses original fitSize/track .03, native wMax and min(.14u); step=1.75size, L0=max(.9H-step*k,2size), paper width=measured text width+.8size. L_i=L0+step*i, Lmax=L0+step*(k-1), T_i=period*1.6sqrt(L_i/Lmax). tau=max(0,ltb-.2), rel=inOutCubic(clamp((lt-.1)/.6)); angle=A*side*cos(2πτ/T_i)*rel+inCubic(pOut)*30deg*side*(.5+i/k), A=(fan?7:5)deg*(.5+.7motion). grow=outCubic(clamp((lt-.04i)/.4)); grow<=0 skips body/text and string. miAt(.12+.05i), original gIn/out/fa, and traversal are unchanged.

CRITICAL: recomputing Ti from a shortened/reflowed candidate length or changing k/i changes the animation. First recipes should scale all L_i by one common physical factor, preserving all L_i/Lmax, and use the frozen native Ti to avoid floating-point drift. Never merge, split or reorder the original pendulum objects in this first adapter. Natural line wrapping WITHIN an original chunk paper can change writing geometry while keeping its object/clock; it must map each original source glyph back to its native item and mainDraw run index/mi so wrapping does not restart reveal. If equivalent per-glyph source timing cannot be established, keep that recipe typed unsupported. There is no reveal waiver for visible text detached from its complete paper/bob.
