# AVOID-009 ribbon 独立画像照合

対象は `/tmp/avoid009-ribbon-selected-20261024-01/output` の単一例 `ribbon-landscape`。manifest.json と cases.json を先に読み、その後に実画像を確認した。親へ画像ブロックは返さない。

**判定：確認した14画像の範囲で、変更後だけに生じた重大な新規表示欠陥は認めなかった。** 全240フレームの連続再生評価・円外成立・採用可否の合格を意味しない。文字60%・帯幅70%・波65%の縮小構成を採用してよいかは人間確認待ち。

## 所見

- frame30/60/90/150/228では前後とも「風の先へ」の4文字を左から同じ順序で読める。文字の欠落・入替・重複・潰れは見えない。変更後も濃色文字と黄色い帯のコントラストは十分で、画面全体表示で判読できる。
- 変更後は帯全体が画面下部へ移り、文字・帯・尾が縮小している。frame60/90/150では左右の尾が全体として画面内に収まり、frame228でも本体と短くなった尾が見える。確認画像では下端や左右端による新規の切れはない。
- 中央の明るい帯、折返しの陰影、濃い左右の尾、くびれの接続は前後で対応している。変更後に帯から文字が浮く、文字だけが元の位置に残る、尾の接続が破れるような表示は確認していない。
- frame30→60/90/150→228→239のサンプル間で、中央から帯が開く・両端の尾が広がる・終盤に閉じるという演出の段階は対応している。帯の曲がりと文字の傾きも残っている。サンプル画像照合であり、フレーム間の滑らかさや一瞬の破綻を保証しない。
- **共通の見た目上の問題**：frame15とframe239では、細い中央帯に対して「の」「先」が横へはみ出し、暗い背景に重なる部分の文字が読みづらい。前後とも同じ段階で起きており、変更後固有の新規欠陥とは認めなかった。全4文字を常時読める演出ではない。
- 変更後の余白は上側に大きく、帯は下部にまとまる。縮小後も帯として識別でき、文字と帯の組合せに明白な不自然な断絶は見えない。ただし構図・縮小率の好みや、元の迫力を十分保てているかの最終評価は人間に委ねる。

## 根拠と限界

- ローカルffprobeを前後両MP4へ実行し、両方とも h264 / 1280×720 / 60/1 fps / 240 frames / 4.000000秒を返した。ffmpeg抽出コマンドはexit code 0で完了した。
- manifestが記載する前23a62ee・後caddb6a、同じ条件の単一例「風の先へ」を照合した。manifestの自己申告の成功判定を視覚判定の根拠にはしていない。ハッシュの再計算は行っていない。
- 初期8blankframeは共通の既知挙動という指定を受けたが、このレビューではframe0〜8を追加実査していない。
- 原寸MP4・静止画に回避円のoverlayはない。画像から円の外側成立を証明したとは言えない。幾何条件・raw240framesの数理レビューは別作業。
- ローカルファイル読取、ローカル画像表示、ffmpeg/ffprobe、専用ディレクトリへの抽出と本文保存のみ。公開URL接続、HTTP、追加サイバー調査、実装変更、Git操作、Sites操作は行っていない。
