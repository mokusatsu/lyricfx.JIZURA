# Fisheye next-strategy source audit 01

Read-only design findings from fixed baseline `6e016f7:src/11p_layoutsD.js` fisheye and current `src/09l_layoutsD_fisheye.js` / current fisheye source. No browser/network/image/test execution. No claimed acceptance or safe-case count beyond parent's supplied result.

1. **Use independently coherent rows as the next placement units.** Native glyph positions are `x_i=C_r+½(Σbefore b_j k_j−Σafter b_j k_j)`, `y_i=Y_r`, with `k_i=1+A λ exp(−((a_i−L)/σ)²)`. The native reflow is relative to a row center, so replace `W/2` consistently with row center `C_r`; translate that whole row and its active lens/grid together. Preserve reading order, native source occurrence/motion index, per-row lens progress and row phases. A few ordered upper/lower or left/right row lanes are coherent; individual glyph scatter is not. Bound and check inter-row overlap and readable gaps after placement.

2. **Try native-size row placement before changing font size.** Existing `rowPitch>1` enlarges the same joint vertical hull; it cannot route separate rows on opposite sides of a circle. Start with existing rows: solve each complete row+owned lens envelope into ordered outer lanes. If needed, split at existing chunk/word boundaries into two/three sequential lines with a declared source-to-row map. For rewrapping, preserve global occurrence indices and global sweep progress rather than silently recalculating `mi=ri*3+i*.5` or resetting lens timing. Preserve pingpong phase by native source row (or explicitly declare an altered phase strategy). A changed row count changes native sweep scheduling; it needs explicit intended choreography, not an incidental consequence of wrapping.

3. **Outer bands give a concrete feasibility criterion.** For circle center `(cx,cy)`, radius `R`, stage margin `m`, a full-width upper lane must fit within `[m,cy−R−m]` and lower lane within `[cy+R+m,H−m]`; a row envelope of height `h` can occupy a lane iff `h` fits its height. At usual `(0.5W,0.42H), R=0.2 min(W,H)` in landscape, nominal upper/bottom band heights are `0.22H`/`0.38H`, before guards. Thus bottom lane often offers more height than upper, but safe fit is conditional on actual glyph/lens/camera ink. Circle-chord side lanes or mixed upper/bottom/side layouts can admit native-size text where full-width lanes do not. Use the real geometry solver and writing-field constraints; never declare a guaranteed fit merely from this arithmetic.

4. **Keep the moving lens attached to the correct row.** Sweep: at most one row normally has `L≠null`, with two at the exact shared endpoint; source assignment overwrites `lensPos` in row order, so final glass lens belongs to the last eligible row at that boundary. Pingpong: every row has a lens position but the source draws only the last row's glass lens. Grid mode draws a grid per active row. A split row adapter must model these native distinctions and change owner IDs to row-qualified units if independent row offsets are used. A global `fisheye.lens` envelope spanning all rows would defeat independent placement and could place the visible lens on the wrong row.

5. **Tighten correlations analytically instead of taking unrelated extrema.** Current center bounds let every other glyph independently choose `k=1` or `1+A`, which no single Gaussian lens can realize. Partition the finite rest-coordinate lens domain `L` into intervals. For each glyph and interval `[L0,L1]`, the Gaussian's minimum is its farther-endpoint value; maximum is `1` if `a_i` lies inside the interval, otherwise its nearer-endpoint value. Combine signed prefix/suffix sums with `λ∈[0,1]`. This is a rigorous enclosure for every continuous time, not a sampled union. Refine only intervals whose certificates are inconclusive. As interval width tends to zero, residual independent-Gaussian overestimate vanishes; retaining a separate independent λ interval remains conservative. Partition exact nearest-rest-center midpoint boundaries to identify `best` for the lens, with native first-index tie rule (spaces remain candidates in source). Bound lens center and radius using the same correlated interval. Frame-clock sampling is not a substitute.

6. **Use exact primitive extents for lens markers.** Glass lens radius has native maximum `max(0.95*1.25*s0*(1+A/2),1.05*s0)`. Its handle end is center plus `1.75R*(cos50°,sin50°)` and half stroke is `1.3*lw` (native line width `2.6lw`), with the recorder's actual cap/join/AA/camera guard. Circle rim is `R+lw/2`. Derive x/y one-sided extrema from these primitives; current symmetric `4lw+4` and global total-row width are conservative, sometimes expensive. Do not drop all lens geometry to increase pass rate. Grid warp has radial displacement `0.9 A λ r exp(−r²/(1.4σ)²)`; its global radial displacement maximum is `0.9 A (1.4σ)/sqrt(2e)`. Add that to the finite native grid-point rectangle (native polylines interpolate vertices) instead of multiplying every x/y endpoint by `1+0.9A` independently.

7. **Continuous font-size proof must match the actual drawing model.** The baseline `fontCSS(s0*k)` can change hinting/optical sizing/fallback behavior with size; measuring only maximum CSS size and adding zero to its hull does not prove all smaller sizes. Pinning font bytes alone supplies no Canvas API theorem that all hinted glyphs scale inside that hull. Existing Canvas `measureText` returns one state's metrics, not a continuous-size bound. Raw font-table Bézier extrema give unhinted outline bounds but still need an established bound on hinting, fallback, variable axes and raster support before certifying actual Canvas output; arbitrary one/two-pixel allowances are not that theorem.

8. **The current fixed-CSS implementation is the grounded finite method.** Current source already draws each ON glyph with one CSS size `s0` and `sx=sy=k`. Measure that exact glyph/font/state once via existing `A.itemGeometry`; with positive `k∈[kmin,kmax]`, each coordinate endpoint is bounded by `min(kmin*v,kmax*v)` / `max(...)`, then compose source/camera transforms and the established recorder raster guard. This preserves continuous effective size and lens reflow while allowing ON hinting/AA to differ from baseline. It is stronger than the old maximum-CSS-size assumption. Zero-hull for `k∈[1,1+A]` is safe but looser than the signed endpoint calculation. If exact varying-CSS native rasterization is mandatory, the current APIs cannot establish its continuous envelope; either introduce a controlled outline renderer or a finite explicit CSS-size quantization with exact-state metrics (which changes size continuity). Do not call either a proof of the unchanged native variable-CSS path.

Recommended sequence: correlated native joint certificate; native existing-row independent lane certificate with correctly attached lens; declared coherent chunk-wrap lanes at native size; narrower native lens amplitude/path if allowed; discrete local font reduction last with per-source size floors. Every rejected candidate stays explicit; no whole-effect small rectangle, circle mask, detached glyph scattering, or silent lens removal.
