# B25 final font fixture proposal (pending parent review)

The native transport single-Noto fixture is not final font-role or typeSpecimen acceptance. Proposed final fixture API: `runLayoutsBFixture(J,spec,{newPath,fontURL,fonts})`, where `fonts` is `{version:1,faces:[{id,family,url,weight,style,label,sourceSHA256,cmapSHA256}],assignments:{fontKey:faceId}}`. `fontURL` remains the explicit single-face transport mode. Final review config must supply `fonts`; before and after execute the identical fixture/options/font bytes. All URLs are relative to the bundle and carry raw-byte manifests, including fonts. Do not retain any oldbundle ../font paths.

Proposed minimum six genuinely distinct Japanese faces: local Noto Sans CJK JP Regular/Bold and Noto Serif CJK JP Regular/Bold, plus actual DotGothic16 Regular and M PLUS Rounded 1c ExtraBold from the original font family's ordinary HTTPS Google Fonts text-subset endpoint. Use the system Noto JP collection face (not SC/TC/HK), subset the same known source codepoint inventory with fontTools, and retain source/licence/download metadata and original source hashes. If a requested face/download is unavailable, state failure or substitute a clearly named actual face in both runs; do not label Noto as DotGothic/M PLUS. Extra Dela/Zen/etc faces may be added if needed to preserve a selected source branch; explicit fixtures choose native keys corresponding to actual faces.

The assignments use real role distinctions: body=Sans Regular, display=Sans Bold, serif=Serif Regular/Bold, rounded=actual M PLUS, pixel=actual DotGothic16, mono=local Noto Sans Mono CJK JP Regular. For typeSpecimen freeze main/font-key arrays to six different actual faces; g2/g3/list branches all retain their full original specimen counts and different faces. All visible specimen labels/name/weight come from the actual assigned face; the manifest separately records original native role→actual fixture face so no original-name impersonation occurs.

Build a codepoint inventory from exact text/lineText/note/specimen labels, source-generated metadata, poolOf/KATA substitutions, romaji, row headers, No./LINE/TIME digits, all fixture branches and English/JA UI strings relevant to review. Include Latin/punctuation/symbols and compare cmap coverage. If CJK fonts lack symbols, use an explicitly disjoint symbol subset as a recorded fallback; verify actual fonts for every emitted glyph and reject tofu/missing glyphs. Do not silently allow Latin-only or symbol-only system fallback.

Before Canvas measurement await every FontFace.load(), add it, await document.fonts.ready, verify document.fonts.check() for the actual faces and representative text, then clear J.metrics/J.glyphs. Record loaded faces, actual assignment/weight, subset cmap hash, glyph coverage, and distinct metrics/raster signatures for typeSpecimen. A CJK monospaced clone with identical Japanese glyphs is not counted as an additional visually distinct specimen merely because its family name differs.

Before comparison is explicitly `e96cbb2 + full-stage original native composition fixture` (legacy small avoidance rectangle removed). After is the same stage/seed/lyric/line/fonts/source clocks with B staged avoidance. It is not described as a same-switch-only comparison against old ordinary UI ON. Old small-rectangle ON, disabled/OFF, manual/lock/explicit size remain separate controls with their actual plan properties recorded.
