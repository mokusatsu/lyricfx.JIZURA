## Common proof obligations

- Distinguish semantic source identity from current draw text: use `(source field, occurrence/range, logical copy, fragment, owner, pass)`. Repeated characters require occurrence ranges; a matching character string is insufficient. Reveal substitutes have the owning final slot range plus pool-entry provenance. Generated labels need their own field/record identity. Owned shapes need owner IDs even when not lyric-bearing.
- The source uses different normalizers: `clean` deletes whitespace (8); `slotsOf` trims/collapses whitespace to one ASCII slot (10); `mainLines`/`splitL` insert line breaks and merge punctuation-only lines (14–18,64–68); `glyphPts` removes ASCII/fullwidth space (50–52). Keep an explicit normalization map into original fields. JS spread indexes code points, not Unicode grapheme clusters or UTF-16 offsets. Do not silently call all these source ranges grapheme ranges without a real conversion map.
- `poolOf` (70–81) is non-Latin/non-punctuation characters from `(lineText||'')+text`, excluding `・`, concatenated with even-index KATA characters. It is nonempty because of KATA; duplicates retain their pool-entry identity. Final Latin/punctuation characters need separate measurement because they can be absent from the pool. Fonts, language faces, stroke, tracking, ruby, suppression, FX and AA must be included. Font-size proportional metric scaling requires a demonstrated conservative font-ink bound; hinting/raster rounding cannot simply be assumed homothetic.
- All layout-local envelopes still need the shared `J.mainDraw` enter/hold/exit envelope, contentScale, camera, pass/ghost affine transformations and their source motion-time domain. Those implementations were not independently proved in this advisory. `lt` controls local entry; `ltb` controls persistent motion; `pOut` controls exit; project realTime selects the avoidance region. They must not be substituted for one another. Require finite positive W,H,dur, finite normalized pOut in [0,1], known font and finite parameters, or explicitly diagnose unsupported input. Plan ranges below are not validation: imported/custom params can exceed them.
- Only source-tagged geometric entry/exit can qualify for temporary passage relaxation. Fade, reveal clipping, glyph substitution, steady scroll/sway and all hold events remain strict. A short cut may never reach a sampled rest state: source event identities and envelopes must exist even if absent at `min(1.5,dur/2)`. One midpoint or 96 playback frames does not prove the continuous interval.
- Bound source-native clips exactly and independently from the full owned text/plate quality check. Native clip preservation is legitimate; adding a circle exclusion clip or using opacity/plate occlusion to omit primary is not. Contact remains collision; include max(2px,.005 short side) and alpha>=1/255 support.
- For a local rectangle with half extents a,b at angle theta, use rotated corners or `hx=|cos theta|a+|sin theta|b`, `hy=|sin theta|a+|cos theta|b`; if angle varies, isolate quadrant/stationary extrema or use radius sqrt(a²+b²). Metadata and stroke extend that rectangle. Returned `bb` is often only main text, unrotated or absent: it is not a complete composition bound.
- `outBack(x,s)=1+(s+1)(x-1)^3+s(x-1)^2`, x in [0,1] (src/01_util.js:24), has maximum `1+4*s^3/(27*(s+1)^2)` at `x=1-2*s/(3*(s+1))`. For s=2 this is 275/243≈1.131687. Use the exact maximum for focus dots/elbow mark, including exit product <=1; never cap these at 1.

## slotMachine (988–1053)

Identity/ownership: each non-space normalized slot i owns cabinet/window, all intermediate reel j symbols, each blur offset, final main glyph and cylinder shading/frame. Cabinet spans all cells including whitespace slots (1010–11); rows own payline and arrows (1042–48). Keep `(i,j,blurOffset)` separate from final `(i,final)`; intermediate j=FIN before settle and main final after settle are different native event branches. Use source range for final slot and pool entry for substitute. Window clip is fixed `[c.x-w/2,c.x+w/2]×[c.y-h/2,c.y+h/2]` (1021); final mainDraw is inside that clip too (1033–34).

Domain: v in [13,18], style cabinet/window, line boolean (992); fits 1..10 but `n=slotsOf(text).length` is the actual geometry input. cellRows uses maxPerRow portrait5/landscape10, aspect1.34, maxK=.24M, gap .1 (999; helper848–860). `w=k,h=1.34k,step=.92k,gsz=.7k`; cabinet padding .22k. Frame stroke max(1.5,.02k); arrows reach `.28k` beyond cell x-extrema; payline stroke max(1.2,.012k), arrow halfheight .1k. Include geometric ghosts on cabinet via gIn, not just fixed glyphs.

Whole time: `gap=clamp(.3dur/n,.08,.2)`, `t1=clamp(.16dur,.2,.45)`, `ts=t1+i*gap`. Before settle p=1000-v(ts-lt); after settle `p=1000+.22 sin(30(lt-ts))exp(-(lt-ts)/.08)` (1018). Coarse valid post-settle displacement bound is `.22step`; pre-settle every enumerated j has |j-p|<=2, blur adds .16step, so pre-clip glyph support is centred within ±2.16step plus measured glyph ink. Intersect with fixed native window for transported ink. Do not replace complete pool measurement by the visible midpoint glyph. After settle final mainDraw also has shared entry/hold support, not merely reel displacement.

Split boundaries: lt=ts, ts-.05 (fast blur branch), p integer crossings before settle; oscillatory integer crossings after settle if proving exact identities (coarse full-pool/window envelope avoids enumerating them). The local sine can oscillate indefinitely on a long cut, though its decaying envelope is finite. `inA` reaches1 at .25; gIn changes at .6 and pOut=0. Reel substitution and cabinet fade do not create relaxation. Recipe: retain slot i order, reel phase ts/v/j and window clipping; wrap whole cells into ordered rows, resize cabinet to their union and regenerate paylines/arrows per row. Do not independently place blur copies.

## credits (1119–1171)

Identity/ownership: main lyric `mt`; ordered semantic records `vals` formed from lineText||text, chunkText, segments with glyphCount>=2, reading, note, LINE, TIME. add() deduplicates by trimmed **value only**, so first surviving role wins (1135); a NOTE matching a lyric can disappear natively. Preserve native surviving records, their original provenance/ranges and labels, rather than manufacture all requested labels or accidentally remove further records. Each record has `(semanticRecord, repeat occurrence, label/value fragment)` identity. All visible repetitions are primary finite semantic records, not auxiliary tiling. Side separator owned.

Domain: variant center/side/single; portrait side resolves to center; speed .035..06, off0..10. fs=clamp(.026M,14,36), rowH=2.3fs, block=(vals.length+2)rowH. Actual `lineText`, note and label lengths are not limited by fits16. Main lyric size<=.16H and width .44W side/.72W otherwise. Values can be arbitrarily wide and must be measured/rewrapped honestly.

Whole time: scroll=(ltb+off)*speed*H, remainder `r=scroll % block` (1145/1150), initial y=1.05H-r-block*ceil(1.1H/block), then y+=block with rep<12. JS `%` is a signed remainder: negative ltb/ghost lag can produce r<0; replacing with positive modulo changes native behavior. Exact phase discontinuities at scroll=k*block; speed0/custom negative/NaN need explicit handling/guard. Rows are enumerated only for yy∈[-rowH,H+rowH]; alpha<.01 skip, edge fade and centre band fade (1153–57) are strict, not safe passage. Conservative value corridor is that entire yy interval plus measured glyph ink. Single label centre yy-.95fs; other labels share yy and have right-align at cx-.9fs, values left-align cx+.9fs. Finite alpha gates can narrow the proof only with exact support analysis, not an assumed empty centre band. `rep<12` can truncate visible repeats on tall/custom conditions: source-coverage must follow this cap, not assume infinite tiling.

Critical phase invariant for recipe: changing block changes temporal period `block/(speed*H)`. To retain native semantic cycle use native normalized phase `scroll/nativeBlock` and native record/repeat order, then map its geometry; do not silently reuse speed with a new block or reset off for each lane. Side lanes keep rows moving in a clear corridor and labels attached; main lyric remains separate hierarchy and separator follows its lane. For branch-exact source certificates isolate modulo boundaries, yy viewport gates, alpha=.01 crossings and repeats; conservative full corridor may avoid alpha root solving but must still account for finite repetition identities. No scroll entry/exit relaxation during hold.
