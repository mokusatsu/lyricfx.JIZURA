# Next construction: dictionary logical-copy columns

This is design work after checkpoint4c3d36d, not implemented acceptance. Default dictionary-page fails native-measure correspondence because bodyRows recomputes cpr/rows and therefore the actual repeated copy. Reducing point size also hits the actual secondary floor. Neither is a physical impossibility finding.

The next source recipe should derive a native logical page once, before changing any print field: headword (ordered exact main), guide header, romaji, mark/POS, each definition with its native source truncation, each context bodyRows occurrence (including original last-row randomness), and thumb index with edge rule. Each owner needs explicit occurrence ID, exact full emitted source copy, font identity/point floor, native reveal timing and read order. For bodyRows, fix native fs, cpr, row count, seed offsets, last-row lengths and original occurrence reveal vis before reflow. A new column may split a native occurrence into consecutive fragments; concatenate exactly per occurrence, keep its source reveal opacity and preserve order. Do not concatenate across repeated occurrences or count a different repetition as equivalent. Main split is separate and must preserve ordered cut text and source mi.

A bounded source recipe may then place one dictionary entry column plus context columns and a thumb edge at that column's exterior; it should keep page/entry morphology, POS bracket adjacent to headword and definition bullets attached to definitions. Column measure, native point size, gutter, local header/page edge and context distribution should be explicit source parameters. Full W/H stay fixed; main and its owned furniture share an actual compound placement. The original native joint translation remains the first candidate.

Correspondence proof must compare owner IDs, occurrence IDs, concatenated exact copy, font/actual point size and original reveal curve. It must include ordered fragment ranges with no gap/overlap and actual source event tags for each fragment. shape changes are allowed only with owned correspondence (one bullet per unchanged definition, bracket attached to POS, highlighter exactly native headword lines, page/column rules identified). The strict event clock and pre-clip writing-field checks remain active; this is not a relaxation of the global metadata equality check for all IDs.

Before implementation, numerical diagnostics should expose native owner extents, point floors, proposed column capacities and the complete actual corpus. Dedicated negative cases must reject swapped/omitted/duplicated occurrence fragments, altered font/point size, changed reveal order, detached POS/bullet, clipped last fragment, and stale certificate. Existing matrix04 inputs/results stay immutable. New reflow evidence must have new filenames and before/after pins. Normal-circle success is measured independently of native OFF identity, explicit-size preservation and source-geometry sufficiency.
