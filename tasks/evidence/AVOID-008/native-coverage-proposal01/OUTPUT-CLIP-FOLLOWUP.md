# Follow-up: bounded visible-output transport without a Gaussian certificate

**Conditionally feasible, and narrower than the original Gaussian proposal.** For the actual finite destination Canvas, every pixel written by native item blur is necessarily within that Canvas bitmap, regardless of the filter's mathematical tail. A conservative rectangle covering the actual output-stage clip is therefore a valid bound for **visible destination ink**. This can support an explicit conflict-only shadow transport with real measurementSupported, original blur replay and typed insufficient. It does not establish an un-clipped glyph/filter support envelope, a safe composition or stage-crop preservation certificate. The distinction must be enforced in code/typed scope rather than left in a comment. This is still a proposal; no implementation, jobs or new measurements occurred.

## Source coordinate facts

09a35–36 currently uses a **1×1 measurement Canvas**, not32×32. A.record84–89 resets/uses that surrogate while preserving the real env.ctx matrix; it is an operation recorder, not a pixel image of the final destination. Its 1×1 dimensions cannot define the blur's actual output domain. Native planning09j10–13 creates this surrogate with allowFilter:false. Merely returning its canvas rectangle would be false, and merely using plan.W/H without a destination-domain contract would also be false.

Renderer.frame09_render69–71 takes cw/ch from the actual destination canvas, independently of plan.W/H and opt.scale. It does **not** assert cw=plan.W*scale or ch=plan.H*scale. It sets a scale transform at121; camera/content transforms are then applied at244–252 before placement.render. Therefore the actual runtime bound for the blur item is the device-coordinate rectangle D=[0,cw]×[0,ch], **not** the item matrix applied to the stage rectangle. The canvas boundary is fixed in device space, regardless of camera rotation, shear, pan or contentScale. Existing event.matrix/nativeTransform must still retain the genuine drawing transforms for replay.

Item args remain untouched and09a210 replays through stock J.drawItem. This selects the real drawItemLayered/direct branch using the actual replay destination size (03_text64–118), preserves filter-string rounding and native layer clipping, and requires no recorder reimplementation of the Gaussian kernel. The recorder must continue intercepting the item before raster work; no blur layer is allocated in measurementContext. Blur-disabled native execution must be recorded as its genuine distinct allowFilter:false path, not substituted for true. Parent-reported benchmark inputs must remain unchanged; source coverage must separately record which filter branch the actual perf options exercised.

## When this bound is inappropriate; fail closed

- Actual destination is larger/smaller than the declared stage-scaled canvas; padded outside-ink audit, atlas, tile, export crop viewport or later unverified draw into another canvas. A padded replay can reveal blur outside the original stage; reject this capability there rather than claiming the stage rectangle encloses that ink. An audit deliberately reproducing the native stage clip would only test native **visible** output, not un-clipped filter tails.
- Direct makeEnv/A.record on an arbitrary context without a trusted declared frame domain; its planW/H or surrogate canvas size is not proof. A narrower inherited clip only decreases visible support, but exact native replay must preserve it; no clip may be enlarged or dropped and still claim equality.
- Nonzero joint translation, reuse of D as a local source support that is later transformed, offset solving by moving its vertices, or using a pre-camera stage rectangle as if it were post-camera output. Inverse-camera transforms could map D into another coordinate system, but a plain [0,W]×[0,H] source box is not that mapping.
- Postprocessing/transitions/compositing/export after capture that relocates/resamples/expands the source into an unvalidated different destination. The current stock cam/cut layers09_render208–260 are allocated at the same cw/ch and composited at identity device coordinates, so their bitmap endpoints can share D when that chain is explicitly checked. Their existence alone is not proof for arbitrary external renderers. Initial narrow scope should reject unreviewed downstream spatial mixtures/masks rather than borrow the output bound as a complete provenance proof.
- Using this path for native crop-dominance, full ink inclusion, glyph visibility/field acceptance, or any safe candidate. Separate raw glyph/full ownership checks remain necessary. Filter-enabled and disabled source graphs must both match native pixels; their blur programs need not have the same item args or shape support.
