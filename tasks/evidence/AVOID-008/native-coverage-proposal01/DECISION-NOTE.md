**Prefer finite genuine support, not an unlimited shadow redesign.** Shared blur transport must first prove actual measurementSupported, record/replay identity (actual allowFilter true and false), whole native owned graph, pixels and clocks. Only then can the real solver return typed insufficient for the unchanged shadow composition. A hardcoded variant-to-insufficient result or invented broad bounding box is not acceptable. Under camera/native clipping, apply the actual measured transformed paper and existing stage/crop scope: do not extrapolate that local necessary condition into a claim about every conceivable camera/corner or creative redesign.

Finite candidate study for the unchanged variant should record: native joint translation; finite source-local lyric relocations/reflow retaining the same fixed full paper/lattice, rejected by the same measured paper-circle condition when it applies; split/reordered/sliding panels rejected as changing the shadow variant's fixed architectural and occlusion meaning. Source-local lyric changes cannot remove a paper conflict. **Whole-window shrinking is prohibited**; the optional framed construction discussed in PROPOSAL.md is not an admissible fallback for this task and should not be implemented. Any future intentional new framed design would require a separate explicit product scope, not a renamed viewport shrink. Do not classify the paper/wash/lattice as independent scenery by copying open's source exception.

This leaves a meaningful bounded endpoint: genuine native filtered source transport + actual finite attempts + typed source-measured insufficient when they fail. Keep unsupported if filter/kernel/full owned graph proof remains unavailable. This supports native path coverage without pretending avoidance safe, and does not prove all redesigned shadow treatments impossible. Parent can compare that cost with the separately named open/shelf supported-domain performance corpus while preserving the original mixed-native FAIL.
