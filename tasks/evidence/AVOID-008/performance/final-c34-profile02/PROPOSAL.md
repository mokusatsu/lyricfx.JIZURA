Recommendation is a source-domain audit before any contains edit. For ordinary immutable numeric polygon/point arrays, pos/neg flags are monotone and pos&&neg early false preserves the final predicate even with degeneracy/NaN comparison outcomes, using each module's exact epsilon and arithmetic order. Skipping later reads is not equivalent for accessors/proxies/mutable arrays or exceptions; therefore no blanket early exit is proposed as accepted. Establish all four callers' plain own-data numeric array provenance through recorded polygons and frozen certified envelopes; otherwise retain the old loop for uncertain inputs. Required falsifiers include later throwing getters, mutated length/coordinates, sparse arrays, NaN/Infinity, near±epsilon and degenerate/reversed/self-crossing polygons.
