# 電球：候補作成の計数診断（86az）

実装担当 gpt-6.1-sol / medium。86ayの作成区間に限定した集計診断を実施し、親が55固定入力・4 raw の hash と mock 92項目を確認した。診断用8 KiBは既存8 MiB上限内に予約。計測区間4,088.5 msで、replay budget 8,017回・内包時間3,754.6 ms、codec 32,098回・内包時間3,675.8 ms、owner account 8,024回・内包時間2,413.3 ms。これらは入れ子であり合算できない。前回12,034.8 msと今回の差には単発変動があり、改善の証明ではない。

同じ source-only 経路の j=60 描画 hash と、偽・失効の拒否を維持。通常実行の支配的な重複計数を特定する診断であり、製品性能や通常UIへの接続を認可しない。次は不変な私有modelの計数を再利用し、可変部分と全出現回数の計上、失効検査を維持して同条件で比較する。
