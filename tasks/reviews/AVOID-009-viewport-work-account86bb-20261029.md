# 電球：私有固定データの計数再利用（86ba/86bb）

実装担当 gpt-6.1-sol / medium。owner内で再帰freeze済みの model 由来部分に限り符号化済み byte 数を再利用し、出現回数分を加算する試作。可変の groups・held・現在値・追加作業は都度計数し、memo と一時参照も8 MiBに計上。親は差分を確認し、旧完全計数との一致を都度検査する audit 版を含む mock 各31項目を再実行した。

同じ準備済み model・context を baseline → memo の順で使用した実Canvas単発比較は、候補作成3,998.2→3,800.3 ms。126描画記録とRGBA hashが一致し、偽ticket・世代失効・旧ticket再使用は描画前に拒否。親が66入力・4 rawの hash と paired checker を再実行。計測順序や変動があり、約5%の差を一般的な性能保証にしない。文字・字体・円変更の実Canvas試験はこの比較に含まれない。

この試作も製品未適用。元準備は約33秒、作成は約3.8秒で通常UIの性能条件は未達。入力・世代・容量等の制約を維持して残る重複計数を確認する。
