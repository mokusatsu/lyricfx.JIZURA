# AVOID-009 runtime envelope80 — source-only design

This is a proposed replacement for the slow runtime proof, not implementation or acceptance. The approved six comparison versions remain approved. Existing source75–79 overlays, raw evidence and the optional atom fast path are retained; none is deployed by this document.

## Problem and provisional targets

The diagnostic-disabled fixed-upper cold acquire took 1,021,578.7ms. Representative preflight plus native drawing reached 1,256.6ms. Input-signature changes currently cause four recipes ×727 raw source/paint/quality observations and another727 destination observations; each normal frame repeats source observation and geometry/quality checks. A circle change also rebuilds circle-independent source geometry. These costs fail practical operation.

For fonts-ready, supported single-cut input, the provisional targets are first finalization/edit <=1s, circle-only edit <=100ms, and additional ordinary-frame p95 <=3ms against the same native renderer/context. They do not alter existing formal performance criteria. Measure API work separately from UI end-to-end: normal src/12_ui.js currently calls J.plan, while layoutsD:true finalization is an explicit validation API. General UI finalization, typed diagnostics and output handling remain an AVOID-009/017 dependency; API timing is not UI E2E acceptance.

## Supported domain and unchanged obligations

Start with the existing bulbs board/chase domain, positive uniform push camera, fixed plain cut/still/cut operations and noPost. Preserve original native painting, primary/ghost ownership, every lamp/halo/glint, number/subtitle, text order, native N(t), q/out, native font selection and per-pass clocks. Main text remains the declared single-codepoint/grapheme bounded domain; explicit rows, complex clusters, explicit size and unknown FX stay typed unsupported. Failure to establish an envelope must never trigger the old17-minute fallback or omit the effect.

Keep circle margin2.7, source font/device AA foundations, all quality hard thresholds and the serialized8MiB definition. This is not a universal font/libm/raster theorem or a JS heap/RSS bound. The existing shared Canvas exception-state defect remains separate; no renderer exception-recovery redesign is included.

## 1. Extract an honest native geometry descriptor

Factor pure geometry operations from the native source and reuse them in original painting and compilation. Separate static layout (native brk, font, m100, nativeSize, ss, subtitle content/size, padding/face geometry) from per-clock values (q/out, native rim outline/N, light phase). Preserve the original no-binding operation order; do not compute previously post-cull/post-face work early on the normal path.

The descriptor has an explicit derived-model kind, source revision and dependencies. It is not a fabricated complete native Canvas catalog. Native N(t) and caption sizes come from the same source geometry functions. If the existing recipe68 binding requires a literal observed catalog, use a separate private model80 lease; do not forge the old catalog kind or weaken its guard. Direct rendering uses the descriptor/lease while original unbound rendering stays identical.

Separate ownership from diagnostic capture. Current nativeD=true also builds sourceCalls, ring/light catalogs and recursively freezes them on every frame. Runtime model80 must keep the source ownership contract without allocating these detailed arrays/catalogs. A separate explicit offline capture lease enables the original complete diagnostic catalog only for acceptance/debug runs. Normal observations must report detailedPaintCollected=false (or null evidence), never an empty observed-paint array that pretends collection occurred. Measure ownership/direct-source overhead separately from offline capture cost. No paint, owner or clock is removed to achieve this separation.

A cheap scalar clock compile may enumerate every reachable quantized own.lt/ltb and evaluate the same source operations. Existing Float64 whole-number preimages cover these values; this is neither time sampling nor per-frame draw/spy execution. Confirm from source that this domain has no unquantized realTime dependence except fixed-region selection. Store exact raw sizes and q bits. Derive N for rendering from source functions/cache, never force a fixed native lamp count.

## 2. Metrics and transforms

Canvas hinting prevents treating maximum font size as a linear ink bound. Enumerate all reachable CSS font declarations from the scalar schedule and measure each required glyph in the exact accepted text state. Share metrics by accepted CSS declaration/glyph/text-state, but keep glyph-anchor keys separate: equal rounded CSS sizes can still have different raw size, track, lead and positions. Caption truncation, line-number content, source glyph indices and composite-font choice remain source-derived.

For CTMs, prefer a source-derived outward interval proof. If the existing conditional foundation cannot establish Canvas composition rounding, capture only the native root/matrix skeleton for the bounded scalar schedule, with zero source paint calls. The common camera/ghost schedule is reusable across text and circles. Glyph-anchor transforms may similarly use matrix-only skeletons; they must not quietly assume exact real arithmetic. These inexpensive scalar/matrix operations are distinct from the old all-frame raw render/atom/quality walk and must meet the first-operation target.

## 3. All-clock envelopes and held quality

Face, outline and shadow follow the source rounded shape and q. Bulb/halo/glint centers lie on the inset outline, so conservative rim envelopes can cover every possible center without recording every painted lamp at every time. Keep separate source ghost suppression and main ownership; do not invent ghost lamps/metadata or drop source owners. Use all reachable scalar q extrema (or outward intervals) and root intervals, optionally split into entry/held/exit to avoid unnecessary overestimation. Unknown or unproved shapes return typed unsupported.

Prove or conservatively bound floating interpolation in resampling: a mathematical convex hull alone is insufficient if finite-double f/lerp may leave it. The denominator/zero-segment case and N cap must be included. Likewise account for native Canvas text-transform rounding and all AA/stroke margins.

Held quality has q=1 and a fixed source native N for the given input. Test the source-derived held ring once against every potential halo, logical neighboring bulbs, real glyph/row/face/outline/number gaps, using a proven lower bound on camera scale and conservative transform/text bounds. Preferred gaps stay diagnostic. This time-invariance reduction must be justified before replacing repeated quality observations. If all-potential halos are too conservative, retain a source-derived visibility/phase envelope, not an unproved exclusion.

The compiler must preserve a useful solution for approved fixed-upper/right examples and at least one predetermined nonfixed input. It may conservatively report insufficient space for other inputs. A finite-envelope failure is not an ink-collision or global-impossibility proof.

## 4. Separate cache keys and runtime work

- Clock/root cache: stage, fixed cut timing, fps/koma, camera, effective motion/chroma/ghost and source/helper/context identities. No text or circle dependency is omitted unless source independence is established.
- Source geometry cache: complete safety-relevant source inputs, text/lineText/line metadata, params/seed, raw geometry and font state, plan/page language, context text state, source/helper revisions, plus the clock/root key. Region position/radius are excluded only after this independence is established.
- Circle certificate cache: geometry key plus complete plan/region signature, radius/margin and policy. Changing a circle re-evaluates bounded envelopes/candidates; it does not render all clocks. Changing text, font, source operations or source dependencies must never reuse the old geometry.

Use exact canonical values/Float64 bits, not a hash match alone. Keep bounded entries and an explicit combined serialized budget for retained model, metrics, clock references, certificate and current work/transient data. Count immutable entries once as they are added, then verify the final full size; avoid serializing the whole clock/model thousands of times during compilation. Preserve the existing serialized-working-budget meaning, including any local atom-cache additions; do not label it physical heap.

Normal font APIs increment metrics.revision (02_fonts.js addUserFont/loadFontFile, restoreFontFiles and loadingdone; clear increments at194). Preserve appropriate font identity/dictionary checks as well. Direct FontFaceSet manipulation is not newly qualified by the billboard legacy descriptor-only check.

Chosen eviction protocol: keep the bounded geometry cache and reject a frame whose geometry was evicted; do not recompile in frame. Add an optional non-painting/non-compiling D runtime-admission callback to the private adapter registry. Both the early finalized-plan shortcut in09a and a completed-plan hit in09g must consult this callback before returning an old certificate. A missing model causes a normal finalization miss, allowing that same explicit finalize call to rebuild once from original lineage. Include admission callback identity in completed-cache dependencies, without treating mutable cache residency as a permanent certificate. Other adapters without this optional guard retain their current behavior. Preserve async newer-input rejection. Required test: compile A/B/C to evict A; old A frame rejects before bitmap; a single ordinary finalize(old A or original A) restores admission without manual cache clear; subsequent frame performs no compilation. Also test a completed-cache decoded alias and imported/stale certificates. This is a cache admission change, not renderer exception recovery.

Miter/line state must be explicit in the model context contract. The old raw preflight observed actual lineJoin/cap/miterLimit, while contextState did not fix miterLimit. Either key and prove those states or conservatively support only the declared standard state before any drawing. Do not silently inherit a larger unproved miter. Normal/offline capture and native-baseline comparisons must use the same declared context.

A frame must perform only dependency/input/font/context/root/own-clock checks, certificate ownership and issued-token checks, then the same native source direct drawing. It must not compile or scan all clocks on a frame cache miss. Missing/evicted/imported geometry yields an explicit stale/unsupported result before bitmap writes; explicit finalization restores it. Test missed, reused, foreign and finished tokens. Any model/native mismatch must fail before drawing; no silent native fallback for a bound unsafe recipe.

## 5. Offline acceptance stays exhaustive

The old fixed-upper full raw audit remains a numerical reference, never a runtime atlas. For model80, independently verify at every native clock that every positive paint support is contained by its model envelope; validate native N, full glyph/metadata order, source RNG/phase and direct output against the original closure. Accepted destinations require all primary circle/stage checks and full250 native/product/oracle comparisons. Keep source-only equivalence, live Canvas evidence and practical timing as separate gates.

Predeclare cases before execution: approved upper/right fixtures; duplicate風風先先/seed1206/upper mustAccept; EN-page/en-plan HELLO/upper mustAccept; one-character, long text, moved and enlarged circle, explicit size/rows/extra FX failures, and normal font replacement. The EN-page case uses a native English baseline build, not just Latin text in a JA page. Test circle-only geometry-cache reuse, text/font invalidation, plan changes and eviction/rebuild. Do not make every nonfixed input insufficient and call it generalization success.

Measure first compile, circle edit, warm cache, ordinary-frame additional cost and native cost separately, with no heavy raw audit running concurrently. Diagnostic I/O overhead is a separate measurement. Formal performance, all D IDs/FX and whole009 completion remain unaccepted until their own conditions are met.

## Transfer to the other approved effects

The source75–79 seams/proof prototypes are retained as source and offline acceptance inputs. After bulbs80 establishes a working compiler/certificate boundary, design input-derived envelopes for billboard attached board/lights/posts, one-row domino rigid poses/source-X clipping, whole burst plate/rays/debris, contour hero and native body/metadata groups, and crossword grid with native number/clue sizes. This document is a design gate, not a claim these are solved.
