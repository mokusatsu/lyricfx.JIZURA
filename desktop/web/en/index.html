Lyrics

  • One phrase per line. A blank line adds a short pause.
  • ｜　　　｜ … Spaces between full-width vertical bars create a lyric line with effects only and no text
  • I remember/the dawn … / marks a cut boundary
  • Wrap multiple lines in { and } to stack them until the final cut disappears.
  • {- and -} around lines … retain successive lyrics while avoiding overlaps.
  • First line\nSecond line … \n adds a line break within one cut (use \\n to display it literally).
  • *emphasis* … a larger automatic area, displayed above the foreground without avoiding it.
  • ~whisper~ … a smaller display with gentler motion.
  • A trailing ! … adds a flash and shake
  • 50:Lyrics … Cut placement size (100 = full frame, 50 = half width and height; overrides automatic size limits). To display the number and colon, use 50\:Lyrics
  • lyrics|reading or note … Smaller text in annotation layouts (supported effects only)
  • [01:23.45]Lyrics … uses an LRC timestamp
  • # starts a comment (ignored)
  • Place \ before a control character to display it literally: \*, \~, \{, \}, \/, \|, \!, \#, \[, \\.
