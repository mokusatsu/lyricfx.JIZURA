# 回避タイムラインの操作対応

回避タブの「円形領域を追加」「人物マスクを追加」、またはタイムラインの「再生位置で編集 → 挿入 → 回避」から種類を選ぶ。追加時の開始・終了は 0 秒から追加時のプロジェクト終端で、確定するまでプロジェクトは変わらない。追加後はカットのメニューから編集し、端のドラッグでも時間を調整できる。複数の領域は同じ時間に重ねられる。

| 設定 | 追加画面／タイムラインの変更画面 |
| --- | --- |
| 有効、開始・終了、次カットまで、ガイド、ロック | 円・人物それぞれの画面 |
| 重なった部分、前景を背後に隠す | 円・人物それぞれの画面。重なった部分は表示／補助描画のみ／歌詞全体から選択 |
| 中心・半径、配置回避、強調、マスク半径・ぼかし・勾配 | 円の画面。位置・サイズはプレビューでも変更可能。マスク詳細は遮蔽選択時に有効 |
| 自動配置に戻す、以降にも同じ配置 | 円の変更画面。後続の人物とロック済みカットは対象外 |
| 人物素材、解析状態、解析画面への導線 | 人物の画面。背景・前景の素材名と時間を表示 |
| 人物解析の範囲、fps、実行・中止、進捗と結果 | 選択した背景・前景素材の人物解析画面。マスクは素材側に保存 |

人物遮蔽は回避区間と参照素材の区間が重なる時間に適用される。素材未選択・未解析・解析範囲不足・解析済みは人物画面に表示し、解析先は選択中の素材名を表示する。

ブラウザ回帰は日英画面で追加のキャンセル、全域初期値、既存カット・リンクの維持、同時開始カットの端ドラッグ、円の設定、人物の素材・状態と解析画面、編集キャンセル、undo/redo、保存・再読込、ガイドとプレビューを確認する。人物解析の画面内の生成操作はスタブと生成済みマスクの fixture を使うため、実モデル推論の検証ではない。すべての設定値の組合せや全フレームの描画を網羅するものではない。
